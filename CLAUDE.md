# Правила команды — в другом репозитории

Канон: `anatoly9837-lab/Cafe13KPG`, файл `AGENTS.md`. **Этот файл — КОПИЯ одного
правила, не источник. Расходятся — прав канон.**

**Коммиты без `Co-Authored-By`-трейлеров.** `Claude-Session` в коммите и строка
«🤖 Generated with …» в теле PR остаются: по ним находят сессию.

Остальные правила читаются командой, целиком и без чекаута:

    gh api -H 'Accept: application/vnd.github.raw' \
      repos/anatoly9837-lab/Cafe13KPG/contents/AGENTS.md > /tmp/AGENTS.md
    grep -c 'Коммит агента не несёт трейлера' /tmp/AGENTS.md   # 1 — канон на месте
    grep -c "НЕТ-$RANDOM-$$" /tmp/AGENTS.md                     # 0 — прибор различает

⚠ Односторонность НАРОЧНО: второй копии правил здесь не заводить. Копия в часто
читаемом файле становится источником де-факто и расходится с каноном молча —
у нас это уже случалось.
