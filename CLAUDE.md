**Коммиты без `Co-Authored-By`-трейлеров.** `Claude-Session` в коммите и строка
«🤖 Generated with …» в теле PR остаются: по ним находят сессию.

      repos/anatoly9837-lab/Cafe13KPG/contents/AGENTS.md > ~/.cache/kanon/AGENTS.md

    grep -c "НЕТ-$RANDOM-$$" ~/.cache/kanon/AGENTS.md       # 0 — прибор различает

Само правило о трейлере с 02.11.2026 живёт **не в `AGENTS.md`**, а в блоке,
и спрашивается своим адресом:

    gh api -H 'Accept: application/vnd.github.raw' \
      repos/anatoly9837-lab/Cafe13KPG/contents/_docs/rules-pr.md > ~/.cache/kanon/rules-pr.md

печатала 0** — то есть «канона нет» о живом правиле: ревизией 02.11.2026 оно
уехало в блок, а признак остался прежним. Нашла `designer-55` 06.11.2026,
прогоном. Это ровно тот класс, о котором предупреждает абзац ниже: копия в
часто читаемом файле осталась единственным источником, канон переехал, и
расхождение молчало. Поэтому признаков теперь два, у каждого свой адрес, и
каждый с контролем различения.

файл под общим именем принадлежит не тебе. Прежняя редакция писала в
`/tmp/AGENTS.md`.
