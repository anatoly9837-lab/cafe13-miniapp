# Какие приборы `tools/` занимают батарею (браузер)

Перечень снят 26.11.2026 на стволе сразу после мерджа #485 (роль klient-lezhachie2, поручение coordinator-3).
Зачем он нужен: у двух приборов имя скрывает браузер (`check-recepty.py`, `pered-pokazom.cjs`), и 26.11 оба
поднимали контейнер посреди чужих ворот. **Прибор из списков «всегда» и «в части режимов» гонять только в
выданном слоте.** Прибор не из перечня (новый, переименованный) сначала проверить признаком ниже.

## Главное, два пункта

1. **`pered-pokazom.cjs` поднимает браузер ВСЕГДА (шаг «дым»), и ключа, который снимает дым, нет.** Поэтому любая проверка номера версии этим прибором стоит слота. Номер вне слота проверять `grep` по `js/01-osnova.js` (`VERSION`) и `index.html` (`?v=`). **Долг:** ключа `--без-дыма` нет, проверка номера требует батареи; заводить ли его, решает координатор.
2. **`check-recepty.py --перечень` ничего не исполняет** (`:314–321`), это дешёвый режим без браузера и без слота: печатает блоки документа и счёт команд. Браузер поднимают обычный прогон и `--самопроверка`.

⚠ **Граница.** Перечень собран **по тексту**: попадания признака прочитаны глазами, вызовы процессов
(`subprocess`, `spawnSync`, `chromium.launch`) найдены поиском. Это признак, а не замер. Ни один прибор ради
перечня не запускался с подсчётом контейнеров. Где по тексту не решить, стоит «проверить замером».
Перечень стареет с каждой правкой `tools/`: сверять с признаком, а не верить на слово.

**Признак** (для нового прибора и для сверки перечня):
`grep -lE 'playwright|live\.cjs|docker' tools/*`, затем каждое попадание **глазами** (часто это
комментарий), затем `grep -nE 'subprocess\.|spawnSync|execSync|chromium\.launch' tools/<прибор>`:
прибор может звать другой прибор, а у того уже браузер.

## 1. Поднимает браузер всегда

| прибор | как |

| `pered-mergem.sh` | шаги 1–3 — `docker run` образа playwright: `live.cjs` двумя частями, `shots.cjs`, `vidimost.cjs`. Шаг 18 зовёт `check-recepty.py --самопроверка` (тоже docker) |
| `pered-pokazom.cjs` | шаг «дым»: `tools/smoke.cjs`. Если `playwright` в node рядом, то в node, иначе `docker run` образа (`:63–64`). Браузер в обоих путях. Ключей, которые снимают дым, нет |
| `live.cjs` | `chromium.launch` (`:215`). Запускается внутри образа |
| `shots.cjs` | `chromium.launch` (`:376`). Внутри образа |
| `smoke.cjs` | `chromium.launch` (`:51`). Внутри образа |

## 2. Поднимает в части режимов

| прибор | режимы |
|---|---|
| `check-recepty.py` | **`--самопроверка` — всегда**: пять `docker run` образа playwright (`:474–530`), 26.11 на дереве `09c7ba9` шла 10 с. **Обычный прогон** (`--файл <документ>`, по умолчанию корневой `README.md`; `--только N` — один блок) исполняет команды из блоков ```bash через `bash -c` (`:262`). В `README.md` блоки с `docker run` образа есть (`:65`, `:124`, `:137`, `:258`), поэтому по умолчанию тоже браузер. Документ или блок без `docker` по тексту браузера не поднимает — **проверить замером**. **`--перечень`** только печатает блоки и ничего не исполняет (`:314–321`): браузера нет |

- Вне `tools/` приборов не искала: каталога `scripts/` в дереве нет, остальное поручением не охвачено.
- Прибор, который поднимает браузер **без нужды**, по тексту не найден. Дым `pered-pokazom.cjs` нужен по
  предмету (ворота показа). Неудобно другое: имя не говорит о браузере, и проверку одного лишь номера

  `index.html`.
