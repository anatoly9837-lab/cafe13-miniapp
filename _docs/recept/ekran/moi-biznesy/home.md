# `home` · группа «Мои бизнесы» на «Клубе»

Рецепт БЛОКА внутри чужого экрана: имя файла — ключ хозяина (`home`). Карточка
дела — `myBiz.md`. Граница «одно дело / два» — `sostav.md`, раздел «Граница».

**Зритель:** человек с грантом `bar` или `curator` на ДВА активных дела и
больше. У остальных «Клуб» не меняется ни одной строкой.

## Слова

| что | слово |
|---|---|
| `H1` подпись группы | `Мои бизнесы` |
| `H2` строка дела | `.listitem`: `<b class="clamp2"><title></b>` — слово сервера; `.pill` `закрыт`, если `is_open` ложно; `.chev`. Подстрочника нет, `accent` нет — как строка «Бизнесы клуба» на «Услугах» |
| `H3` загрузка | `.card quiet` `.small` `Загружаем бизнесы…` |
| `H4` не загрузилось | `.card strong`: `<h2>Бизнесы не загрузились</h2>`, `.verbatim` — слово отказа (`failText`/`denyText`), `.btn` `Повторить` — тем же действием, что на «Услугах» (`klub-biz-retry`) |

## Блоки сверху вниз

На месте группы «Работа», перед ней:

| блок | когда |
|---|---|
| `.group` `H1` + строки `H2` в порядке сервера | два своих дела и больше |
| `H3` вместо строк | список ещё не пришёл |
| `H4` вместо строк | список не пришёл с отказом |
| `.group` «Работа» — только «Заявки на членство» | если она есть у человека; иначе группы нет |

Нажатие `H2` — выбор дела приёмом `bizPick` (`sostav.md`) и вход в `myBiz`.

## Запрещено

- группа `H1` при одном своём деле (лишний шаг всем ради двоих);
- строки бара в «Работе» рядом с группой `H1`;
- «Заявки на членство» внутри группы `H1`: это клубное, к делу не привязано;
- дело, на которое у человека нет гранта `bar`/`curator`, в группе `H1`;
- закрытое направление (`is_active` ложно) в группе `H1`.

**Признак сборки** (цель числом, путь обязателен, единица — ВХОЖДЕНИЯ):
`python3 -I tools/v-oblasti.py js/11-ekrany-klub.js home 'Мои бизнесы'`
— **до сборки 0 (замер по `6c08a3d`), обязано стать 1** — подпись группы `H1`;
`python3 -I tools/v-oblasti.py js/11-ekrany-klub.js home 'myBiz'`
— **до сборки 0, обязано стать ≥ 1** — строка дела ведёт на карточку.

**Проверки:**

- `moi-biz-odno` — куратор ОДНОГО дела: на «Клубе» нет `Мои бизнесы`, строки
  бара в «Работе» как сегодня, «Заказы на баре» открывают очередь этого дела
  одним нажатием (отрицательный контроль: лишнего шага нет);
- `moi-biz-dva` — куратор «Бара» и «Чая»: группа `Мои бизнесы` с двумя
  строками словами сервера; в «Работе» нет «Заказов на баре», «Карточек меню»,
  «Дохода и расхода бара»; нажатие «Чай» → `myBiz` «Чая»;
- `moi-biz-klubnoe-snaruzhi` — тот же куратор с правом на заявки: «Заявки на
  членство» в группе «Работа» на «Клубе», в `myBiz` их нет;
- `moi-biz-chuzhoe` — у человека `curator` на «Бар» и `worker` на «Чай»: дело
  одно, группы `Мои бизнесы` нет;
- `moi-biz-net` — человек без своих дел: группы `Мои бизнесы` нет, «Клуб» как
  сегодня.
