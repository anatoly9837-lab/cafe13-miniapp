# `myBiz` · карточка дела: рабочие строки ЭТОГО дела

Экран новый. Вход — строка `H2` на «Клубе» (`home.md`) или та же строка на
экране бара без выбора (`sostav.md`, раздел «Граница»). Дело к входу уже
выбрано приёмом `bizPick`: `BAR` и `BAR_PICK` — это дело.

**Зритель:** человек с грантом `bar` или `curator` на это дело.

## Слова

| что | слово |
|---|---|
| заголовок | `Бизнес` (`TITLES`) |
| `B1` смена | `shiftBlock()` без правок — как на `barQueue`: состояние смены, `Открыть смену на себя` / `Закрыть смену` по праву |
| `B2` подпись группы | `Бизнес «<title>»` — `title` словом сервера, `.clamp2` |
| `B3` | `Заказы на баре` · `Очередь: принять, готово, выдан` — строка «Клуба» как есть, `accent`, → `barQueue` |
| `B4` | `Карточки меню` · `Новые позиции и утверждение` — строка «Клуба» как есть, → `barCards`; при том же условии `mayCards() && !workerOnly()` |
| `B5` | `Доход и расход бара` · `Выручка и затраты руками, с комментарием` — строка «Клуба» как есть, → `barMoney`; только при `curator` на ЭТО дело или `admin` |
| `B6` остаток | `walletRow('На счёте', …)` с теми же словами, что у партнёра на «Клубе» (шаг 20, `20/ostatok.md`); только если это дело есть в `BW.dirs`. Иначе строки нет: прочерка у куратора нет |

## Блоки сверху вниз

| блок | что |
|---|---|
| `.card strong` | `B1` |
| `.group` `B2` | `B3`, `B4`, `B5`, `B6` — по условиям выше |

## Запрещено

- рабочая строка ДРУГОГО дела в этой карточке;
- «Заявки на членство» и прочее клубное;
- своё состояние выбора рядом с `BAR_PICK`;
- название дела литералом.

**Признак сборки** (цель числом, путь обязателен, единица — ВХОЖДЕНИЯ):
`rg -c 'myBiz' js/`
— **сегодня 0 (замер по `6c08a3d`), обязано стать ≥ 4** — экран, `TITLES`, `BACK`, вход с «Клуба»;
`python3 -I tools/v-oblasti.py js/11-ekrany-klub.js myBiz 'shiftBlock'`
— **до сборки 0, обязано стать 1** — смена внутри карточки дела;
`python3 -I tools/v-oblasti.py js/11-ekrany-klub.js myBiz 'Бизнес «'`
— **до сборки 0, обязано стать 1** — подпись группы `B2`.
