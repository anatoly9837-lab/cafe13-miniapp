# `manage` · группа «Мои бизнесы» на вкладке «Управление»

Рецепт БЛОКА внутри чужого экрана: имя файла — ключ хозяина (`manage`).
Карточка дела — `myBiz.md`. Граница «одно дело / два» — `sostav.md`. Место —
вкладка «Управление» (№91, слово владельца дословно: «Вкладка управление»).

**Зритель:** человек с грантом `bar` или `curator` на ДВА активных дела и
больше. Вкладки «Управление» у него сегодня может не быть — она появляется и
по этому праву (`sostav.md`, «Что тронуть»). У остальных вкладка не меняется.

## Слова

| что | слово |
|---|---|
| `H1` подпись группы | `Мои бизнесы` |
| `H2` строка дела | `.listitem`: `<b class="clamp2"><title></b>` — слово сервера; `.pill` `закрыт`, если `is_open` ложно; `.chev`. Подстрочника нет, `accent` нет — как строка «Бизнесы клуба» на «Услугах» |
| `H3` загрузка | `.card quiet` `.small` `Загружаем бизнесы…` |
| `H4` не загрузилось | `.card strong`: `<h2>Бизнесы не загрузились</h2>`, `.verbatim` — слово отказа (`failText`/`denyText`), `.btn` `Повторить` — тем же действием, что на «Услугах» (`klub-biz-retry`) |

## Блоки сверху вниз

Первой группой вкладки, перед прочими группами «Управления»:

| блок | когда |
|---|---|
| `.group` `H1` + строки `H2` в порядке сервера | два своих дела и больше |
| `H3` вместо строк | список ещё не пришёл |
| `H4` вместо строк | список не пришёл с отказом |

Нажатие `H2` — выбор дела приёмом `bizPick` (`sostav.md`) и вход в `myBiz`.

## Запрещено

- группа `H1` при одном своём деле (лишний шаг всем ради двоих);
- группа `H1` на «Клубе» (№91: место — «Управление»);
- «Заявки на членство» внутри группы `H1`: это клубное, к делу не привязано;
- дело, на которое у человека нет гранта `bar`/`curator`, в группе `H1`;
- закрытое направление (`is_active` ложно) в группе `H1`.

**Признак сборки** (цель числом, путь обязателен, единица — ВХОЖДЕНИЯ):
`python3 -I tools/v-oblasti.py js/17-ekrany-upravlenie.js manage 'Мои бизнесы'`
— **сегодня 0 (замер по `7bebcce`), обязано стать 1** — подпись группы `H1`;
`python3 -I tools/v-oblasti.py js/17-ekrany-upravlenie.js manage 'myBizList'`
— **сегодня 0, обязано стать 1** — строки дел.

**Проверки:**

- `moi-biz-odno` — куратор ОДНОГО дела: на «Управлении» (если вкладка у него
  есть) нет `Мои бизнесы`, строки бара в «Работе» на «Клубе» как сегодня, «Заказы на баре» открывают очередь этого дела
  одним нажатием (отрицательный контроль: лишнего шага нет);
- `moi-biz-dva` — куратор «Бара» и «Чая» без иных прав: вкладка «Управление»
  есть, в ней группа `Мои бизнесы` с двумя строками словами сервера; на «Клубе»
  группы нет, в «Работе» нет строк бара; нажатие «Чай» → `myBiz` «Чая»;
- `moi-biz-klubnoe-snaruzhi` — тот же куратор с правом на заявки: «Заявки на
  членство» в группе «Работа» на «Клубе», в «Моих бизнесах» и `myBiz` их нет;
- `moi-biz-chuzhoe` — у человека `curator` на «Бар» и `worker` на «Чай»: дело
  одно, группы `Мои бизнесы` нет;
- `moi-biz-net` — человек без своих дел: группы `Мои бизнесы` нет, вкладка
  «Управление» и «Клуб» как сегодня.
