# Долги прибора `tools/v-oblasti.py` — закрытые и живые

Это НЕ рецепт: раздела «Признак сборки» здесь нет, и прибор сверки такой файл
не судит (форма — `README.md`). Правило области признака и три негодных способа
— в `oblast-priznaka.md` рядом; здесь только долги САМОГО прибора, каждый с
замером, воспроизведением и правилом «до починки».

## Пять экранов прибору БЫЛИ не видны — долг, закрытый `#277`

Замер 18.11.2026 по стволу `3778e2c`, нашла `designer-55`, пиша рецепт шага 14.
`tools/v-oblasti.py` считает экраны только внутри складки
`Object.assign(SCREENS, {` — так написано в нём самом, и замер в его
комментарии («девять файлов экранов, в каждом один `Object.assign(SCREENS`»)
верен в числе и неполон в перечне: файлов экранов **десять**, и первый,
`js/11-ekrany-klub.js`, объект не дополняет, а ОТКРЫВАЕТ (`var SCREENS = {`).

Поэтому пять его экранов прибору не видны вовсе: `home`, `guest`, `pass`,
`membership`, `memberRequests`. Спрос по любому из них:

    python3 -I tools/v-oblasti.py js/11-ekrany-klub.js home 'Свой бизнес в клубе'
    # v-oblasti: НЕ ВЫПОЛНЕНО — в js/11-ekrany-klub.js нет области `home` (есть: —)
    # rc=2

⚠ **Ложного зелёного здесь нет**, и это заслуга формы отказа: прибор печатает
«НЕ ВЫПОЛНЕНО» и даёт код 2, а не ноль. Ноль читался бы как «текста нет» —
то есть признак на СНЯТИЕ сходился бы при живом экране. Тот же класс, что
перевёрнутая асимметрия в `oblast-priznaka.md`, и ровно поэтому «нечем
измерить» обязано быть отдельным исходом, а не нулём.

✅ **ДОЛГ ЗАКРЫТ** сборкой `#277` (ствол `3274d5f`): начало складки читается и
как `var SCREENS = {`, а в самопроверке стоит отрицательный контроль «экран из
открывающего файла находится». Перемерено мной по стволу `64e0066`:
`python3 -I tools/v-oblasti.py js/11-ekrany-klub.js home '>Свой бизнес в клубе<'`
даёт **0** с кодом **0** — и ноль здесь законный: разметку блока печатает
помощник из `js/06-lyudi.js`, а НЕНАЗВАННОГО файла прибор не видит по
объявленному пределу. Правило «до починки — счёт по файлу» этим не отменено:
его держит теперь следующий долг.

## Однострочный помощник съедает тело СЛЕДУЮЩЕЙ функции — счёт раздувается

Замер 18.11.2026 по стволу `64e0066`, нашла `designer-55`, переводя признак
`13/home.md` на верный путь.

**Симптом:** вхождение в клиенте ОДНО, прибор печатает **2**, и оба адреса —
одна и та же строка:

    python3 -I tools/v-oblasti.py js/11-ekrany-klub.js,js/06-lyudi.js home '>Свой бизнес в клубе<'
    #   partnerOffer (зовёт home) — 06-lyudi.js:871
    #   prTill (зовёт partnerOffer) — 06-lyudi.js:871
    #   2        ← а `rg -o '>Свой бизнес в клубе<' js/ | wc -l` даёт 1

**Причина — граница области помощника.** Конец тела ищется по `^\}` со строки,
СЛЕДУЮЩЕЙ за объявлением (`tools/v-oblasti.py`, `области_файла`). У помощника,
написанного в ОДНУ строку, закрывающая скоба стоит на строке объявления, и
область тянется до первой `}` ниже — то есть до конца тела соседа. `prTill`
(`js/06-lyudi.js:840`) так проглотил всё тело `partnerOffer`.

**Воспроизведение** — четыре строки, без клиента:

    function one(x) { return x; }
    function two() {
      return one('ПРЕДМЕТ');
    }
    #   v-oblasti … two 'ПРЕДМЕТ' → 2, адрес один (a.js:3)
    #   тот же файл, помощник в ТРИ строки → 1 — дело в однострочности,
    #   а не в обходе вызовов

**Сторона ошибки — ЗАВЫШЕНИЕ**, и беды от неё две. Признак на ПОЯВЛЕНИЕ с
верной целью краснеет на верной сборке — ложное красное, громкое. А автор,
записавший раздутое число ЦЕЛЬЮ, купит признак дефектом прибора: с починкой
тот же рецепт покраснеет. Признак на СНЯТИЕ (цель 0) этот класс не трогает —
ноль не раздувается.

**Размер беды:** однострочных функций в клиенте **64** по `64e0066`, больше
всего в `js/09-afisha.js` (18) и `js/07-mastera.js` (12) — задеть может любую
семью, а не только мою.

⚠ **Самопроверка прибора этого НЕ ловит:** `--самопроверка` на `64e0066` даёт
«бед 0», потому что однострочного помощника в её образце нет вовсе. Подлогом
ей годится файл воспроизведения выше, ожидание 1.

**До починки:** признак, чья область захватывает однострочного помощника,
пишется счётом по ФАЙЛУ, и законный остаток называется адресом — как у
признака на снятие. Задет ли признак, видно по выводу прибора: ДВА адреса с
одним номером строки.
**Починка:** конец однострочного помощника читать на строке самого
объявления, плюс отрицательный контроль в самопроверке. Прибор — предмет
ОТДЕЛЬНОГО PR: внутри рецептного он был бы правкой приговора заодно с правкой
требования.
