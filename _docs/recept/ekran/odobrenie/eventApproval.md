# `eventApproval` · очередь арт-директора: ивенты, ждущие одобрения

**Зритель:** держатель роли `art_director`, админ проходит (предикат
`_may_distribute`, api #176 `fc474be`, `app/routers/events.py:1346–1404`).
Право — одобрить или отклонить опубликованный, ещё не кончившийся ивент,
который никто не решал. Свой ивент арт-директор одобряет сам (решение
координатора по прецеденту шага 25, `Cafe13KPG#1009`, комментарий «самоодобрение»).
Экрана сегодня нет, ключ `eventApproval` свободен.

Фича 4 `Cafe13KPG#1009`, дробление фич 4 и 8; решения владельца №40 «б»,
№48 «б» — в афише виден только одобренный ивент, ивенты работников тоже.
После миграции 040 ивент работника, главы и арт-директора рождается
НЕодобренным: без этого экрана новых ивентов клуба не увидит никто, кроме
автора и арт-директора. **Клиент едет вместе с выкладкой api #176** (`/health`
≥ `fc474be`).

⚠ **Код клиента не читался** (правило `Cafe13KPG#975`). Форма ответов — код
сервера на `fc474be` и тело api #176. **Все тексты — ключами перевода**
(№22): `slovo('<ключ>')`, словарь `js/00-slova.js`. Слова сервера (`detail`
отказа, `reject_note`) — не ключи, печатаются как есть.

⚠ **Очередь ОТДЕЛЬНАЯ от заявок мастеров (`masterReqs`) — ВЫБОР**, дробление
оставило его рецепту. Это два разных предмета: заявка мастера несёт 100 ฿,
её отказ возвращает деньги (`master.py:577–585`), согласие РОЖДАЕТ ивент уже
одобренным. Здесь денег нет вовсе («Денег нет», тело api #176): ивент
работника не платит за слот. Общий список смешал бы строки с деньгами и без,
и отказ «с возвратом» читался бы рядом с отказом без него. Заявок мастеров в
этой очереди не бывает: их ивенты одобрены согласием.

## Данные экрана

- `GET /events/pending-approval` — очередь; не-арт-директору 403 «ивенты
  одобряет арт-директор»;
- `POST /events/{id}/approve` — без тела; ответ `{id, approved_at,
  approved_by, rejected_at, reject_note, approval: "approved"}`;
- `POST /events/{id}/reject` `{note}` — ответ тот же, `approval: "rejected"`;
- после любого решения — очередь перечитывается целиком (строка уходит);
- отказы решения — все словами сервера в `A9`: 409 «мероприятие уже
  одобрено» / «уже отклонено» (второй арт-директор успел первым), 409 «не
  опубликовано», 404 «мероприятия нет», 403 «решение по ивенту чужими глазами
  не делается» (просмотр чужими глазами), 422 «назовите причину отказа».
