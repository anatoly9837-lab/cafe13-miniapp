# `event` и `events` · «ждёт одобрения» и «отклонён» у автора

**Рецепт ЧАСТИЧНЫЙ:** только слоты одобрения на карточке ивента (`event`), в
строке афиши (`events`) и на выходе создания (`eventNew`). Остальное на этих
экранах — как сегодня, своих рецептов у них нет.

**Зритель:** автор ивента и арт-директор (с админом). Сервер отдаёт ждущий
ивент автору и `art_director`/`admin`, отклонённый — только автору
(`event_visible_sql`, api #176 `fc474be`); посторонний их не видит вовсе.
В строке ивента новые ключи `approval` (`approved` | `pending` | `rejected`)
и `reject_note`.

Фича 4 `Cafe13KPG#1009` (№40 «б», №48 «б»). **Клиент — вместе с выкладкой
api #176** (`/health` ≥ `fc474be`). ⚠ **Код клиента не читался** (`#975`).
Новые слова — ключами (№22); прежние слова экранов не переводятся.

⚠ **Почему метка обязательна:** ждущий ивент стоит в афише АВТОРА и
арт-директора рядом с одобренными. Без метки автор считает, что его ивент
видят все и на него записываются.

## Слова

| что | ключ | слово |
|---|---|---|
| `E1` `.pill` при `approval = pending` | `event.approval.pendingPill` | `Ждёт одобрения` |
| `E2` под `E1` на `event`, у автора | `event.approval.pendingNote` | `Ивент видите вы и арт-директор. В афише для всех он появится после одобрения, записаться на него до этого нельзя.` |
| `E3` `.pill` при `approval = rejected` | `event.approval.rejectedPill` | `Отклонён` |
| `E4` под `E3` на `event` | `event.approval.rejectedNote` | `Арт-директор отклонил ивент, в афишу он не попадёт. Причина:` и `reject_note` `.verbatim` |
| `E5` на выходе `eventNew` | `eventNew.done.pending` | `Ивент создан и ждёт одобрения арт-директора. До одобрения его видите только вы и арт-директор.` |

⚠ **Отклонён ≠ отменён** (№44, ответ архитектора на план 040): отклонённый ивент
НЕ печатает слов отмены, и отменённый — слов отказа. Это два разных
`.pill`; признак отказа — `approval = rejected`, признак отмены — `state` как
сегодня. Если ивент и отклонён, и отменён — стоит отмена (её сделал автор
позже).

⚠ **Денег в `E1`–`E5` нет:** ивент без заявки не платит за слот («Денег нет»,
api #176). Сто бат и их возврат — только у заявки мастера, их слова живут на
«Ваших букингах» (`../master/home.md`, `H5`, `H8`). Ивент мастера рождается
одобренным согласием на заявку и сюда не попадает.

⚠ **При `approval = approved` метки нет** — ивент как сегодня. Одобренный
переходом 040 (`approved_by` null) от одобренного человеком на экране не
отличается.

## Где что стоит

| экран | `pending` | `rejected` |
|---|---|---|
| `events`, строка ивента | `E1` справа от названия | `E3` справа от названия |
| `event`, под заголовком | `E1`, `E2` (`.small`) — у автора; арт-директору `E1` и ссылка на `eventApproval` | `E3`, `E4` |
| `event`, запись | кнопки записи НЕТ (сервер ответит 409 «не проводится») | кнопки записи НЕТ |
| `eventNew`, после создания | `E5` (`.small`) на выходе | — |

`.pill` — тот же класс, что у `status_ru` на `../master/home.md`; уровень «признак»: фон `--sage` для `E1` (ждут), `--clay` для `E3` (отказ)
— по брендбуку (`../../sostav-shkaly.md`); класс — ПРЕДПОЛОЖЕНИЕ, судит опись.

## Данные

- `GET /events` и `GET /events/{id}` — `approval`, `reject_note` в строке;
- `reject_note` — слова арт-директора, печатаются как есть, `.verbatim`.

## Перечитать на входе

Как сегодня: `event` — на каждый вход. Решение арт-директора автор видит
следующим входом; уведомлений нет (тело api #176).

## Запрещено

| запрещено | прибор |
|---|---|
| ждущий ивент без метки в афише автора | случай `odobr-metka` |
| кнопка записи на ждущем или отклонённом | случай `odobr-zapis` |
| отклонённый со словами отмены, отменённый — со словами отказа | случай `odobr-ne-otmena` |
| слова о деньгах у отклонённого ивента без заявки | случай `odobr-bez-deneg` |

**Признак сборки** (ВХОЖДЕНИЯ, сумма `rg -c` по файлам `js/`):
`rg -c 'event.approval.pendingPill' js/` — **сегодня 0, обязано стать 3**
(словарь + `events` + `event`); `rg -c 'event.approval.rejectedNote' js/` —
**0 → 2**; `rg -c 'eventNew.done.pending' js/` — **0 → 2**.
