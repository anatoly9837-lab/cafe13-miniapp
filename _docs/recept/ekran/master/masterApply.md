# `masterApply` · букинг мастера: одна дата за 100 ฿

**Зритель:** член клуба, не гость, с живым членством (кнопку «Забукать» на
«Клубе» гость не видит; подачу без живого членства сервер отвергает сам).
Право — подать букинг на свободное время календаря со СВОЕГО счёта. Решает
арт-директор на `masterReq`.

Шаг 4 «Вход в клуб как мастер», новая модель — слово владельца 20.11.2026:
«Он букает только один ивент теперь. На следующую неделю надо букать
следующий»; «Сколько угодно — каждый по 100 ฿» (ТЗ `Cafe13KPG#985`, редакция 2).

⚠ **Код клиента не читался** (правило `Cafe13KPG#975`). Форма ответов — снимок
сервера в `#985` (api `d75c445`); слова — выбор
дизайнера. ⚠ **Рецепт идёт ВСЛЕД сборке** (`#365`, v174) — ошибка постановки,
названная координатором; рецепт — основание описи и мера расхождения.

## Вход / Выход

| откуда / куда | как |
|---|---|
| вход | «Клуб» (`home`) → блок «Ваши букинги» → кнопка `M0` «Забукать»; ждущий букинг вход НЕ закрывает |
| `M8` | один `POST /master/request`; удача — назад на `home` с `M10`, список перечитан |
| отказ | остаёмся здесь, поля сохранены, `M9` |
| назад | `home` |

## Слова

| что | слово |
|---|---|
| `M0` кнопка на «Клубе» | `Забукать` — глагол владельца («букает») |
| заголовок экрана | `Букинг на дату` |
| `M1` под заголовком, ВСЕГДА | `Букинг — один ивент на одну дату. Подача стоит <amount> ฿ при любой длине занятия; откажут — деньги вернутся на счёт. На другую дату — новый букинг.` |
| поля | `Название`, `Описание`, `Мест` (`0` — без ограничения), место `Зал` строкой, без выбора |
| `M2` | `Дата и время`: дата (не раньше сегодня, по умолчанию завтра) и время шагом 30 минут; `Часов` — от 2 до 12 |
| `M3` занятость даты | заголовок `Занято в этот день`; строка `ЧЧ:ММ–ЧЧ:ММ «<title>»`; ждущий чужой букинг — `title` сервера как есть; пусто — `В этот день свободно` |
| `M4` пересечение | `Пересекается: <starts_label>–<ends_label> «<title>»` — из `conflict` |
| `M5` прошедшее время | `Это время уже прошло — выберите другое.` — при `fits: false` без `conflict` |
| `M5b` дата раньше сегодня | `Выберите дату — сегодня или позже.` |
| `M6` цена | `Спишется · <H> часа <amount> ฿` — `amount` из `/master/price` |
| `M7` недостача | `Не хватает <N> ฿` строкой у кнопки; кнопка погашена |
| `M8` кнопка | `Отправить букинг` |
| `M9` отказ подачи | `.deny` → `.verbatim`: `detail` сервера как есть |
| `M10` удача, на `home` | `Букинг отправлен` |

⚠ **`100` в разметке нет: число — адресом** (`/master/price` → `amount`).
Цена от часов не зависит, но клиент её не знает — знает сервер.

⚠ **Дата не подставляется из прошлого букинга** — остальные поля подставляются
(`#697`): прошлая дата всегда в прошлом или занята этим же мастером.

## Блоки сверху вниз

| класс | слова | источник |
|---|---|---|
| `.small` | `M1` | `amount` — `/master/price` |
| `.card` | поля, `M2` (`.field`) | — |
| `.card quiet` | `M3`; под ним `M4` или `M5` | `GET /master/slot-busy?place_id&date&start_local&hours` |
| `.card` | `M6` (`.num` у суммы), `M7`, `M8` (`.btn`) | `/master/price`, остаток счёта |
| `.deny` → `.verbatim` | `M9` | ответ `POST /master/request` |

## Данные экрана

- `GET /master/price?hours=H` → `amount`;
- `GET /master/slot-busy` ОДНОЙ даты: `busy[]`, `conflict`, `fits`; ответ о
  другой дате не принимается (пользователь успел сменить дату);
- `POST /master/request` `{title, about, seats, place_id, starts_on, start_local, hours}` —
  без `weekday`;
- остаток счёта — тем же источником, что шапка.

## Состояния

| состояние | что на экране |
|---|---|
| **свободно** | `M3` «В этот день свободно», `M6`, `M8` жив |
| **пересекается** | `M4`; `M8` жив — свободу проверяет сервер, `M9` скажет отказ |
| **время прошло** | `M5`, `M8` погашен |
| **не хватает** | `M7`, `M8` погашен |
| **отказ сервера** | `M9`; поля сохранены |
| **занятость не загрузилась** | `Занятость не загрузилась` и `Повторить`; `M8` жив — сервер проверит сам |
| **цена не загрузилась** | `Цена не загрузилась` и `Повторить`; `M8` погашен — без цены не сказать, сколько спишется |

⚠ «Пересекается» НЕ гасит кнопку — ВЫБОР: из двух (гасить по `conflict` /
отдавать серверу) взят второй, потому что `conflict` снят до нажатия и
стареет. Отменяется, если люди жмут и получают отказ чаще, чем меняют время.

## Перечитать на входе

Цену и занятость — на каждый вход и на каждую смену даты, времени, часов.

## Усечение

`title` занятости в `M3`/`M4` — одна строка, носитель `.clamp1`.

## Снято этим шагом

Экран продления `masterRenew` (кадры E59, E59b) — СНЯТ СОВСЕМ: подписки и
продления нет. Строки «в месяц», «ещё час — N ฿», «Занято в этот день недели»
сняты вместе с недельной моделью.

## Запрещено

| запрещено | прибор |
|---|---|
| `weekday` в теле подачи | случай `offer-send` |
| цена константой в клиенте | случаи `offer-short`, `offer-exact` (цена в заглушке 130) |
| ждущий букинг закрывает форму | случай `buking-mnogo` |
| занятость другой даты на экране | случай `slot-busy-chuzhaya-data` |
| «пересекается» на прошедшем времени | случай `slot-vremya-proshlo` |
| экран и дверь продления | признак `masterRenew` ниже → пусто; случай `prodlenie-net` |
| телеграм-id и живое имя в разметке | `tools/ids-clean.cjs`, шаг 7 ворот |

**Признак сборки** (цель числом, единица — ВХОЖДЕНИЯ):
`git grep -c 'masterRenew' -- js/ index.html`
— **обязано стать пусто** — экрана продления нет (в стволе `45b7d59` ключ стоит
в `screens/СТАДИИ.tsv:110`, то есть есть и в клиенте);
`git grep -c 'Оплачено будет до' -- js/`
— **обязано стать пусто** — слово снятого экрана;
`git grep -c 'Отправить букинг' -- js/`
— **обязано стать не меньше 1** — слово `M8`;
`git grep -c 'starts_on' -- js/`
— **обязано стать не меньше 1** — дата в теле подачи.
⚠ «До сборки» у новых слов не названо — следствие `#975`.

**Проверки** — ветви ТЗ, касающиеся экрана:

- `offer-send` — тело несёт `starts_on`, `start_local`, `hours`, без `weekday`;
- `offer-short` — остаток меньше `amount` → `M7`, кнопка погашена;
- `buking-mnogo` — второй букинг при ждущем первом подаётся;
- `buking-data-proshla` — дата раньше сегодня не уходит, `M5b`;
- `slot-vremya-proshlo` — `fits: false` без `conflict` → `M5`;
- `prodlenie-net` — экрана и двери продления нет.
