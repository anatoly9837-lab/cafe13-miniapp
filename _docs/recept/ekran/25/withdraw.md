# `withdraw` · запрос на вывод заработанного

**Зритель:** любой, у кого есть ЗАРАБОТАННОЕ — `withdrawable > 0` (фича 6
`Cafe13KPG#1009`, решение владельца №41: «Выводит любой, у кого на счету есть
заработанное»). Роль `master` больше не условие. Право подать запрос на свой
счёт в пределах заработанного; решать его он не вправе. До фичи 6 зритель был
держателем роли `master` (шаг 25).
Экрана сегодня НЕТ (паспорт, поле 1: `git grep` по `withdraw` и «вывод» в
`js` — о деньгах 0), ключ `withdraw` свободен.

⚠ **Код клиента не читался** (правило `Cafe13KPG#975`). Встраивание — из
паспорта экрана (`arhitector-b7`, клиент main `ba1c76d`, api main `64955b6`),
слова — из ТЗ шага 25. Образец формы — пополнение (`topup`, паспорт, поле 1):
человек просит, решающий говорит «да» или «нет».

⚠ **Дверь на «Клубе» — ВЫБОР фичи 6** (архитектор не возражает): у человека
без ролей «Управления» нет, а вывод теперь открыт любому с заработанным.
Дверь ОДНА — строка на `manage` снята: две двери к одному экрану разошлись бы
условиями. Условие показа — `withdrawable > 0`, а не роль: при нуле дверь вела
бы в отказ. Отменяется, если вывод вернётся к роли.

⚠ **`W2` и `W11` — сердце рецепта после фичи 6.** На счёте лежат и
заработанное, и пополнения, а вывести можно только первое (ТЗ фичи 6,
отрицательный контроль: «только пополнение — вывести не может»). Без `W11`
человек видел бы `На счёте` и просил бы больше, чем можно. Формулу
заработанного сервер даёт замером до кода; экран её НЕ считает — печатает
`withdrawable`. Прежнее слово шага 25 «вывести можно весь остаток… доля
членского взноса и пополнения» СНЯТО: оно стало неправдой.

⚠ **Новые тексты — ключами** (№22, вид `<экран>.<блок>.<слот>`, словарь
`js/00-slova.js`, функция `slovo()`); прежние слова экрана этой фичей не
переводятся. Минимума суммы НЕТ (ТЗ фичи 6: 1 000 ฿ отменены 21.11).

**Сумму вводит мастер — УМОЛЧАНИЕ АВТОРА, а не «весь остаток» одной кнопкой.**
ТЗ, ветвь 1: «суммы не больше остатка», то есть сумма — его выбор. Поле не
заполняется остатком: подставленная сумма сделала бы вывод всего остатка
действием по умолчанию. Отменяется, если владелец скажет «вывод — только
целиком».

- остаток — `/me`, как в шапке;
- заработанное — `GET /withdraw/accounts`, строка `personal`, поле `withdrawable` (фича 6; поле есть с api #174 `cc40488`,

- подача: сумма → ответ — запрос или отказ;

карточку `#556` со sha api (как на шагах 21 и 24).

выплаты; показывать форму без `W2`; телеграм-id и живое имя в разметке.
