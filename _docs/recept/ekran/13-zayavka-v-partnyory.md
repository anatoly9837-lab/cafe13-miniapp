# Шаг 13 · Заявка в партнёры

Рецепт по форме `README.md` этого каталога. Карточка — `Cafe13KPG#887`,
сборка и случаи — `#889`. Первый рецепт вместо кадров.

**Адреса сервера — по ИМЕНИ функции**: `app/routers/partner.py`, api
`origin/main` `2fff8d6`, замер мой чтением 06.11.2026. Слова сервера сюда не
скопированы: их печатает сервер, клиент печатает полученное классом
`.verbatim` внутри `.deny`.

Девять экранов карточки — это **пять экранов со состояниями**: «ждёт»,
«отказали» и «согласовано» — состояния ОДНОГО блока на «Клубе» (так уже
сделан мастер, `masterOffer`), а «пусто» и «не загрузилось» — состояния
очереди. Отдельными экранами они были бы экранами, которых у клиента нет.
Ничего из карточки не выпало.

⚠ Классы ниже — из рецептов облика (`../recept-вместилище.md` и соседние).
Геометрия и токены сюда НЕ переписаны нарочно: уровень каждого класса, его
радиус и цвет — в **составе этих экранов** (`13-sostav.md`), а значения
уровней — в `../sostav-shkaly.md`. Число живёт в одном месте.

**Усечение:** ввод — пределы сервера (название 1–200, описание до 2000),
обрезки в поле нет; длиннее предела — отказ сервера его словами.

**Запрещено:** доля и `%` (случай 13.4); слово «направление» о бизнесе (случай

**Зритель:** `_is_ops`. **Вход:** `.listitem` очереди. **Выход:** решение →

| класс | слова | источник |
|---|---|---|

| `.card` → `.small` | имя заявителя · когда подана | очередь |
| `.paper` | описание бизнеса целиком | `about` |
| `.rows` | «Списано» · сумма | `amount` |
| `.btn` | «Согласовать» | моё |
| `.btn quiet` | «Отказать» | моё |
| `.field` (после «Отказать») | `.label` «Причина отказа» · подсказка «Что исправить, чтобы согласовали» | моё; требование — `decide`, 400 |
| `.note` | «Согласие создаёт бизнес и начинает оплаченный месяц. Отказ вернёт деньги заявителю.» | моё; механика — `decide` |
| `.deny` → `.verbatim` | печать отказа сервера | `decide` |
| вспышка «да» | «Согласовано» · «Бизнес „…“ создан.» | `title` из очереди |
| вспышка «нет» | «Отказано» · «Деньги вернулись на счёт заявителя.» | моё |

**Данные экрана:** `POST /partner/requests/{id}/decide` ← `decision`, `note`;
ответ → `status`, `decided_at`, `direction_id`.

**Состояния:** пусто — нет; `.sending` на отправке; отказы сервера по адресам
(`decide`): 404 — такой заявки нет; 409 — своя заявка; 409 — уже решена, со
словом статуса; 400 — отказ без причины. «Не загрузилось» относится к очереди.

⚠ **Ответ `decide` не отдаёт ни названия, ни `paid_till`** (замер: возвращает
`id`, `status`, `decided_at`, `refund_ledger_id`, `direction_id`). Поэтому
«Оплачено до …» здесь НЕ печатается: название берётся из уже загруженной
очереди, а дата окна появится на экране партнёра (R1) после перечитывания.
Печатать дату здесь было бы правдоподобным вместо известного.

**Перечитать на входе:** очередь — после отказа 409 («уже решена»): экран
должен показать, кем и как решено, а не повторить отказ.

**Усечение:** описание — без обрезки, `.paper` растёт: решение опирается
именно на него. Название в `.bar` — две строки, дальше многоточием.

**Запрещено:** доля, `%`, любое число доли клуба (случай 13.4 — доли пусты до
шага 21 по миграции 031); «Отказать» без причины (запрет построением: отправка
не работает при пустом поле, и слова сервера на случай обхода); телеграм-id в
разметке (`ids-clean.cjs`).

**Признак сборки:** `rg -n 'partnerReq\b' js/`; случаи 13.4 «отказ без причины
не отправляется» и «свою заявку решить нельзя».

## Заказ серверу

**Цены месяца бизнеса нечем узнать.** `PRICE_MONTH` — константа в
`partner.py`, ни одна ручка её не отдаёт (замер: `git grep PRICE_MONTH` по
`origin/main` `2fff8d6` — только внутри `partner.py`). У мастера для этого
есть `GET /master/price`. Нужна `GET /partner/price` → `{"amount": "…"}`.
Пока её нет, R1 и R2 собираются с погашенной кнопкой и «Узнаём цену…» — экран
есть, купить нельзя. Вписать число в разметку значит соврать при первой смене
цены на сервере.

## Чего этот рецепт не несёт

Общий перечень — в `README.md`. Отдельно по этому шагу: **влезет ли название
на 200 знаков в плашку очереди одной строкой** — правило усечения названо, а
проверяется оно снимком собранного экрана, не текстом.
