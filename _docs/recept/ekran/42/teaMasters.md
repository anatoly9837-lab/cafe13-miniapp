**Зритель:** любой, у кого есть вкладка «Услуги», членство не нужно (см.
`guest.md`). Право одно — смотреть. Бронь начинается в карточке, не здесь.

Доводы — `teaMasters-dovody.md`.

## Блоки сверху вниз

| класс | слова | источник |
|---|---|---|
| `.group` | строки `T1` (`.listitem`) | список СОГЛАСОВАННЫХ карточек — ручка сервера шага 42 |
| `.card quiet` | `T2` | пустой список |

## Данные экрана

- список согласованных карточек: номер мастера, имя, описание, цена строкой,
  первый кадр альбома. Ручки на api нет, имя и форму называет PR сервера
  шага 42. Рецепт требует от ответа ровно эти пять полей (длительность
  списку не нужна, она в карточке);
- цена — строкой, как у ивентов (`price` строкой — память роли «Ручки
  афиши»). Клиент не округляет и не считает.
