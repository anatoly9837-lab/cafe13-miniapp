# `teaReqs` · очередь карточек чайных мастеров

⚠ **№125 (28.11.2026, cafe13-api#250):** карточки чайных мастеров согласует операционный директор, церемонии — арт-директор. Рецепт тронут рукой клиента, зона дизайнера — по слову паркового координатора (park-koord4-7a).

**Зритель:** операционный директор и глава клуба (`mayTeaCards()`, ровно `READS` сервера: `ops_director`, `head`;
админа нет — сервер ответил бы 403). Решает только ОД (`mayDecideTeaCards()`), и решение
принимается на `teaReq`, не здесь. Прежде зритель — арт-директор.

Форма очереди — как у «Заявок в мастера» (`masterReqs`,
`js/18-ekrany-mastera.js:24` на `origin/main` 19a1d99): ждущие сверху,
решённые ниже (цитата 2; доводы — `teaReqs-dovody.md`).

| откуда / куда | как |

## Слова

| что | слово |
|---|---|
| заголовок | `Карточки чайных мастеров` |
| `Q0` группа | `Ждут решения` |
| `Q1` строка ждущей | `.avatar` — первый кадр; имя мастера; `.small` — `новая` или `правка` · день подачи (`topupDay`, как у очереди мастеров); `.st wait` `ждёт` |
| `Q2` группа | `Решённые` |
| `Q3` строка решённой | имя; `.small` — день решения; `.st ok` `согласована` или `.st no` `отказ` |
| `Q4` пусто | `.card quiet`: `<b>Карточек нет</b>`; `.small` `Здесь появятся карточки, которые мастера подают на «Клубе».` |
| `Q5` не загрузилось | `.card strong`: `Карточки не загрузились`, текст ошибки, `Попробовать снова` |

⚠ **«новая» и «правка» различаются** в `Q1` (Р6).
