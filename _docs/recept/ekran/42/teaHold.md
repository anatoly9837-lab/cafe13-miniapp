# `teaHold` · провести чайную церемонию — заявка арт-директору

**Зритель:** любой (№65 «а», `home.md`). Роли, членства и карточки мастера НЕ
нужно. Условие одно — на счёте хватает на заявку (цитата 9). Форма — как
`../master/masterApply.md`: плата при подаче, отказ по деньгам словами сервера,
назад на «Клуб» с отметкой. Доводы и цитаты — `teaHold-dovody.md`.

согласование карточки не заводят, `teaMasters` не меняют.

число сервера, не литерал `100`; бесплатного входа у церемонии нет (№78 «б»).
`C4` под полем входа ВСЕГДА (№68 «а», слово о доле).

⚠ **Гости видят согласованную церемонию в календаре:** строка `L18` в

## Данные экрана

- цена заявки и доля клуба с гостя — сервер (`100` в разметке нет);
- занятость дня читает `calendar`, не этот экран;
- запрос: название, описание, мест, цена входа, дата, начало и конец из
  календаря. Ни места, ни стола;
- остаток счёта — тем же источником, что шапка.

## Заново (№97, №109 «б», №110 — вопрос №115 у владельца)

Слово владельца №97 (26.11): кнопка «заново» «будет запускать создание Event, но автоматически будет заполнять
все по также как в том ивенте». Церемонию заводит ЭТА подача (`POST /master/request`, `occupancy: 'tea'`),
не форма ивента, — поэтому «заново» с церемонии открывает `teaHold`.

| поле `C2` | откуда |
|---|---|
| `Название` | `title` строки архива |
| `Описание` | `about` |
| `Мест` | `seats` (всего, `0` — без ограничения), не `seats_left` |
| `Вход для гостей, ฿` | `price` |

**Не переносится:** дата, время, длительность — их даёт только `C3`, а прошедшее время сервер не примет;
человеку это сказано `C13`, иначе пустое время при заполненном остальном читается «приложение потеряло ввод».
**Снимки:** подача церемонии их не шлёт вовсе (`FOTO_ON.teaHold = false`, `js/09-afisha.js`, `Cafe13KPG#1123`),
переносить нечего; и сервер чужой снимок к новой подаче не прикрепит (api `app/photos.py:334`, 409 `NOT_YOURS`) —
вопрос владельцу №115. Источник — строка `/events/history` по номеру (`histById`); строка не церемония или
не найдена — пустая форма, а не форма чужого вида. Прошлый выбор календаря не подставляется.
