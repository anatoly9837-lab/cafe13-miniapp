# `teaBookReq` · решение по брони церемонии

Как `teaReq.md` (поле слов, две кнопки, «уже решена», отказ сервера). Доводы —
`teaBookReq-dovody.md`.

**Зритель:** арт-директор. Право — согласовать или отказать. Править бронь,
менять время или мастера он НЕ может.

## Вход / Выход

| откуда / куда | как |
|---|---|
| вход | `teaBooks` → `V1` |
| `U5` | согласовать → назад на `teaBooks` с `U7` |
| `U6` | отказать (слова — по желанию) → назад на `teaBooks` с `U8` |
| назад | `teaBooks` |

## Отличия от `teaReq`

| что | слово |
|---|---|
| заголовок | имя гостя `.clamp1` |
| `U1` суть | `.rows`: `Мастер` — имя; `Когда` — `B2`-вид `teaBook`; `Оплачено` — `<price> ฿` (`.num`) |
| `U2` поле | `Слова гостю` — `.field`, необязательное; `.small` `Увидит, если откажете.` |
| `U3` о согласии | `.small` над кнопками: `Согласие займёт это время в календаре клуба.` |
| `U4` о возврате | `.small` над кнопками: `При отказе гостю вернутся все <price> ฿, доля клуба тоже.` |
| `U5` кнопка | `.btn`: `Согласовать` |
| `U6` кнопка | `.btn ghost`: `Отказать и вернуть <price> ฿` |
| `U7` удача согласия | `Бронь согласована` |
| `U8` удача отказа | `Гостю вернули <price> ฿` |
| `U9` отказ сервера | `.deny` → `.verbatim`: слово отказа как есть |
| `U10` уже решена | `.card quiet`: `Эту бронь уже решили.` и `К очереди` |

⚠ **Отказ — это возврат, и это видно до нажатия:** сумма стоит в `U4` и на
самой кнопке `U6` (№86 «а»). У заявки мастера (`teaReq`) отказ ничего не
возвращает — здесь возвращает всё.

⚠ **Согласовать бывает нельзя:** если время церемонии прошло или клуб за время
ожидания заняли, сервер откажет согласию и сам скажет «откажите, деньги
вернутся гостю» — `U9` `.verbatim`. Поле `U2` сохранено, `U6` жив: решение
остаётся за человеком.

⚠ **Своя бронь** (арт-директор — гость или мастер этой брони): сервер отказывает,
`U9`. Экран кнопок заранее не прячет — он не знает, кто ещё арт-директор.

⚠ **Подтверждения мастера на экране нет** — долг сервера (№57 «а»,
`teaBook.md`). Деления денег нет — №93.
