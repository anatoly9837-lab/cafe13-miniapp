# `teaBook` · бронь чайного мастера гостем

**Зритель:** вошедший через Telegram. Право — забронировать мастера на дату и
время со СВОЕГО счёта; членство решает сервер (отказ — `B9`). Бронь — это
церемония, созданная гостем (цитата 5). Цена списывается при подаче и
держится до решения арт-директора (№60); при отказе возвращается ВСЯ, доля
клуба тоже (№86 «а»). Доводы и цитаты — `teaBook-dovody.md`.

⚠ **Подтверждение и отказ мастера (№57 «а») — ДОЛГ СЕРВЕРА.** Словом владельца
у брони два отказывающих — мастер и арт-директор; сервер `cafe13-api`
`a6d4d4c` знает одного, арт-директора. Экран показывает одно состояние брони;
строки «Мастер» нет, пока путь мастера не появится на сервере (долг —
`Cafe13KPG#1115`).

⚠ **Деления денег здесь нет:** куда уходят деньги согласованной брони —
вопрос владельцу №93. Экрана распределения рецепт не несёт.

## Вход / Выход

| откуда / куда | как |
|---|---|
| вход | `teaMaster` → `K5` «Забронировать мастера» |
| `B2` | → `calendar` в режиме «выбрать»; назад — сюда, начало подставлено |
| `B8` | один запрос брони; удача — назад на `teaMaster` с `B10`, перечитать |
| отказ | остаёмся здесь, поля сохранены, `B9` или `B13` |
| назад | `teaMaster` |

## Слова

| что | слово |
|---|---|
| заголовок экрана | `Бронь мастера` |
| `B1` под заголовком | `.small`: `<имя мастера> · церемония <price> ฿` (`.num` у суммы) |
| `B2` время | `.card`: подпись `Время`; пока не выбрано — `.btn quiet` `Выбрать время в календаре` → `calendar` в режиме «выбрать»; выбрано — `Ср, 2 декабря · 19:07–20:37` и `.btn quiet mini` `Изменить` |
| `B2b` окно церемонии | конец = начало + длительность из карточки мастера (№62 «а»); гость выбирает в календаре только НАЧАЛО |
| `B6` цена | `Спишется · <price> ฿` |
| `B6b` под `B6`, ВСЕГДА | `.small`: `Деньги ждут решения арт-директора. Если он откажет — вернутся все.` |
| `B7` недостача | `Не хватает <N> ฿` строкой у кнопки; кнопка погашена |
| `B8` кнопка | `Забронировать`; погашена, пока время не выбрано |
| `B9` отказ сервера | `.deny` → `.verbatim`: слово отказа как есть (`denyText`) |
| `B10` удача, на `teaMaster` | `Бронь отправлена. Ждёт решения арт-директора.` |
| `B11` своя бронь у этого мастера | `.card quiet`, по строке на бронь, новые сверху: дата и время (`B2`-вид); справа ОДИН `.st` — `wait` `ждёт согласования` / `ok` `согласована` / `no` `отказ` |
| `B12` под отказанной `B11` | `.small`: `<price> ฿ вернулись на счёт.`; слова арт-директора, если есть, — `.said` под ней |
| `B13` время занято (отказ сервера «клуб занят») | `.deny`: `<b>Это время уже занято</b>`, под ним `.verbatim` — слово отказа как есть; `B2` сбрасывается в «не выбрано», кнопка `B2` — `Выбрать другое время` |

⚠ **Четыре состояния брони видны все:** ждёт (`B11` `wait`), согласована
(`B11` `ok`), отказ с возвратом (`B11` `no` + `B12`), время занято (`B13` — брони
нет). У `B13` и `B9` сервер сам говорит, что деньги не списаны — слово идёт
`.verbatim`, клиент своего не добавляет.

⚠ **`B13` — не ошибка гостя.** Ждущая бронь времени не держит: календарь мог
показать окно свободным, а сервер к подаче отдал его согласованной церемонии
или ивенту. Сервер судит занятость САМ (№61), не доверяя приложению.

⚠ **Занятость — только в календаре** (`../43/calendar.md`, «выбрать»; цитаты
10, 11). Своей занятости дня и формы времени у `teaBook` нет.

⚠ **Слоты без имён:** календарь говорит «<k> из <ёмкость>», а не «стол 2»;
стол гость не выбирает.

⚠ **Чужие частные брони — без имён** мастера и гостя: только число и вид
«частная бронь мастера» (`../43/calendar-dovody.md`).

⚠ **Любая минута, без шага 30** (вывод ТЗ п. 7).

## Блоки сверху вниз

| класс | слова | источник |
|---|---|---|
| `.small` | `B1` | карточка мастера |
| `.card quiet` | `B11`, `B12` — только если у гостя есть брони у этого мастера | свои брони гостя |
| `.card` | `B2` | выбранное в `calendar` время |
| `.card` | `B6` (`.num`), `B6b`, `B7`, `B8` (`.btn`) | цена из карточки, остаток счёта |
| `.deny` | `B9` или `B13` — один за раз | ответ запроса брони |

## Данные экрана

- цена — из карточки мастера, перечитанной на входе (`teaMaster.md`);
- занятость дня читает `calendar`, не этот экран;
- запрос брони: номер мастера из каталога (НЕ номер пользователя), дата,
  время начала; окно сервер строит по длительности карточки (№62 «а»). Места
  НЕТ (цитаты 7, 8), стола НЕТ;
- свои брони — список гостя, у этого экрана только брони ЭТОГО мастера;
- остаток счёта — тем же источником, что шапка; после подачи и после
  перечитывания отказанной брони — перечитать.

## Состояния

| состояние | что на экране |
|---|---|
| **время не выбрано** | `B2` с кнопкой календаря, `B8` погашен |
| **время выбрано** | `B2` с интервалом, `B6`, `B6b`, `B8` жив |
| **не хватает** | `B7`, `B8` погашен |
| **время занято** | `B13`, `B2` сброшен, поля кроме времени сохранены |
| **отказ сервера** (прочее) | `B9`, поля сохранены |
| **есть ждущая бронь** | `B11` `ждёт согласования` сверху; новая бронь подаётся, ждущая форму не закрывает |
| **бронь согласована** | `B11` `согласована`; отменить её из приложения нельзя |
| **бронь отказана** | `B11` `отказ` и `B12` с суммой |

## Перечитать на входе

Карточку мастера и свои брони — на каждый вход, в том числе на возврат из
`calendar`.

## Запрещено

| запрещено | прибор |
|---|---|
| выбор стола или места | случай `tea-bron-bez-mesta` |
| `3` константой в клиенте | случай `tea-tri-ot-servera` (в заглушке ёмкость 4) |
| своя форма даты и времени вместо календаря | случай `tea-bron-cherez-kalendar` |
| строка «Мастер» с состоянием, которого сервер не отдаёт | признак ниже (`tea.book.stMasterOk` — 0) |
| порядок подтверждений словами («после мастера — директор») | признак ниже |
| кнопка «Отменить» у согласованной брони | на сервере отмены нет — случай `tea-bron-soglasovana` |
| обещание письма мастеру в бота | сервер его не шлёт — `B10` без этих слов |
| имена мастеров и гостей чужих церемоний | случай `tea-chuzhie-bez-imen` |

**Признак сборки** (цель числом, путь обязателен, единица — ВХОЖДЕНИЯ):
`rg -c 'tea\.book\.busy' js/`
— **сегодня 0 (замер по `2c6ce58`), обязано стать ≥ 2** — ключ `B13` и вызов;
`rg -c 'tea\.book\.stMasterOk' js/`
— **сегодня 2, обязано стать 0** — строки «Мастер» нет, пока нет сервера;
`rg -c 'после мастера|после согласования мастер' js/`
— **сегодня 0, обязано остаться 0**.

**Проверки** — ветви ТЗ, касающиеся экрана:

- `tea-bron-bez-mesta` — тело брони не несёт ни места, ни стола;
- `tea-tri-ot-servera` — ёмкость 4 в заглушке → календарь говорит «из 4», а не «из 3»;
- `tea-bron-cherez-kalendar` — на `teaBook` нет поля даты и времени; `B2` ведёт в `calendar`,
  начало 19:07 при длительности 1:30 возвращается как `19:07–20:37`;
- `tea-bron-otkaz-servera` — сервер отказал (не «занято») → `B9` словами сервера, `B10` нет;
- `tea-bron-zanyato` — сервер ответил «клуб занят» → `B13`, `B2` сброшен, `B10` нет, остаток счёта прежний;
- `tea-bron-zhdyot` — своя ждущая → `B11` `ждёт согласования`, строки «Мастер» нет;
- `tea-bron-soglasovana` — своя согласованная → `B11` `согласована`, кнопки отмены нет;
- `tea-bron-otkaz-vozvrat` — отказана арт-директором со словами → `B11` `отказ`, `B12` с суммой и `.said`;
- `tea-otkaz-mastera`, `tea-dva-podtverzhdeniya` — **ждут сервера** (долг №57): до пути мастера не собирать, имена не переиспользовать.
