# `teaMaster` · карточка чайного мастера

**Зритель:** любой, у кого есть вкладка «Услуги». Право — смотреть карточку
и начать бронь (`K5`). Бронь со счёта требует входа через Telegram. Нужно ли
членство, решает сервер шага 42, клиент его не угадывает: отказ придёт словами
сервера на `teaBook`.

Состав и порядок — слово владельца (доводы — `teaMaster-dovody.md`).

## Вход / Выход

| откуда / куда | как |
|---|---|
| вход | `teaMasters` → строка мастера |
| `K5` | → `teaBook` этого мастера |
| назад | `teaMasters` |

## Слова

| что | слово |
|---|---|
| заголовок экрана | имя мастера, `.clamp1` |
| `K1` альбом | `.album`: кадры в порядке, который задал мастер, не больше трёх, все видны сразу — первый крупный, второй и третий превью в ряд; точек нет; кадров нет — блока нет |
| `K2` подпись блока описания | `О мастере` |
| `K3` описание | текст мастера как есть, с его переносами строк; не усекается |
| `K4` цена | `.row`: слева `.small` `Церемония · <Ч:ММ>`, справа `.num` `<price> ฿`; длительность из карточки — ответ владельца №62 «а» (`teaBook.md`) |
| `K4b` под ценой, ВСЕГДА | `.small`: `Спишется со счёта при брони. Если мастер откажет, деньги вернутся полностью.` |
| `K5` кнопка | `Забронировать мастера` — слово владельца |
| `K6` своя карточка | вместо `K5` `.small`: `Это ваша карточка. Изменить её — на «Клубе».` |

⚠ **Порядок:** фото сверху, под ними описание и цена, кнопка внизу — в конце
карточки, не плавает над прокруткой.

⚠ **`K4b` стоит ДО нажатия** (№57 «а»). О согласовании арт-директором строка
не говорит (Р1, `razvilki.md`).

⚠ **Места в карточке НЕТ** (цитаты 7, 8): место мастер пишет в `K3`.

⚠ **Своя карточка не бронируется:** `K6` вместо кнопки. Признак «своя» — номер
мастера равен своему номеру из сервера, а не имя.

## Фото: как попадает на экран

Снимки хранит сервер клуба (рамка владельца 26.11). Поэтому:

- кадр в разметке — адрес СЕРВЕРА клуба вида «кадр N карточки M»; байты
  отдаёт сервер клуба;
- `file_id` и путь файла Telegram в клиент не попадают вовсе;
- кадр не загрузился — на его месте пустой квадрат `--surface`, галерея не
  сжимается.

Имя ручки — за PR сервера.

## Данные экрана

- одна согласованная карточка: номер мастера, имя, описание, цена строкой,
  длительность (№62 «а»), число кадров;
- кадр — по номеру через сервер (выше);
- свой номер — тем же источником, что «своё» в афише (`organizer_id`,
  `js/09-afisha.js:128`).
