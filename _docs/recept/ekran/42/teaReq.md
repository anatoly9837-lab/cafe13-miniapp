# `teaReq` · согласование карточки чайного мастера

**Зритель:** арт-директор. Право — согласовать или отказать. Начать
карточку за мастера, исправить её или выдать без заявки он НЕ может (слово
владельца 29.10.2026, цитата 3; доводы — `teaReq-dovody.md`).

## Вход / Выход

| откуда / куда | как |
|---|---|
| вход | `teaReqs` → `Q1` |
| `R4` | согласовать → назад на `teaReqs` с `R7` |
| `R5` | отказать (слова — по желанию) → назад на `teaReqs` с `R8` |
| назад | `teaReqs` |
