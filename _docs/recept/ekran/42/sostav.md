# Шаг 42 · Состав: чайные мастера

Ингредиенты семьи шага 42: вход на «Услугах» (`guest.md`), список
(`teaMasters.md`), карточка мастера (`teaMaster.md`), бронь мастера гостем
(`teaBook.md`), дверь «Я чайный мастер» на «Клубе» (`home.md`), форма карточки
(`teaApply.md`), дверь арт-директора на «Слотах и мастерах» (`masters.md`),
очередь карточек (`teaReqs.md`), согласование одной карточки (`teaReq.md`),
очередь броней (`teaBooks.md`), решение по брони (`teaBookReq.md`) и
церемония глазами гостя с записью (`teaJoin.md`, №67 «а»).
Разрешённые шкалы и уровни — `../../sostav-shkaly.md`. **Числа здесь не
повторяются.**

Основание и доводы — `sostav-dovody.md` (цитаты владельца, ответы №55–62).
Открытое — `razvilki.md`.

⚠ **Роль одна — `master`** (№58 «б» отменён). «Чайный мастер» — мастер с
СОГЛАСОВАННОЙ карточкой чайного мастера; карточка — вид, не роль. Экранов
мастера (страница, периоды, статистика) шаг 42 не повторяет.

⚠ **Классы — по брендбуку и соседним шагам**, код клиента целиком не читался
(`Cafe13KPG#975`); входы сняты по `origin/main` 19a1d99. Совпадение с
разметкой судит опись.

⚠ **Места у церемонии и ивента НЕТ** (цитаты 7, 8): поля места нет ни в
карточке, ни в брони; место мастер пишет в описании. Во время ивента церемоний
нет.

⚠ **До трёх церемоний одновременно** (№61 «а», число сервера; это не гости).
**Длительность брони** ставит мастер в карточке рядом с ценой (№62 «а»).
**Время церемонии выбирается в календаре** — режим «выбрать» семьи `../43/`;
своей формы времени у `teaHold` и `teaBook` нет. Сервер отказывает занятому
времени и мимо календаря (`../43/calendar-dovody.md`, «ГРАНИЦА»).
