# `partnerStats` · статистика партнёра: деньги его бизнеса за день, неделю, месяц

**Зритель:** партнёр бизнеса — ВЛАДЕНИЕ (`directions.partner_id`), опознаётся
`GET /partner/directions`; роли у него нет (как `../20/bizMoney.md`). У
партнёра с двумя бизнесами — выбор бизнеса, как у `bizWorkers`.

**Образец — шаг 34** (`../34/masterStats.md`, PR #400): владелец 24.11.2026 сказал
«да» его списку и добавил список ивентов с проходом в отчёт; координатор
выводит 33, 35, 36 тем же образцом. ФОРМА — по образцу; **СОСТАВ чисел —
ПРЕДПОЛОЖЕНИЕ дизайнера** в каждой строке, где он назван. Списка ивентов
на этой странице НЕТ — см. «Блока `L` нет».

⚠ **Ручка `GET /stats/partner` есть в стволе api** (`app/routers/stats.py:327`,
main d6ea79b), **в бою её нет до выкладки** (бой 410f240: только `/stats/club`
и `/stats/art`); форма со снимком сервера не сверена.
⚠ **Код клиента не читался** (правило `Cafe13KPG#975`). Тексты — ключами
`partnerStats.<блок>.<слот>` (№22).

## Данные экрана

- `GET /stats/partner?direction_id=&period=day|week|month&at=` — есть в стволе
  api (`stats.py:327`, d6ea79b), в бою нет до выкладки (ПРЕДПОЛОЖЕНИЕ формы до
  снимка со sha api);
- доли — только по закрытому месяцу (вариант C шага 20: доля раз в месяц по
  закрытию); у дня и недели `shares.closed = false` → `H1`;
- `wallet` — та же пара полей, что в `GET /partner/directions`: у одного вопроса
  не два ответа (`../20/ostatok.md`);
- бар бизнеса — источник продаж; касса клуба и чужие бизнесы — не сюда.

**Блока `L` «Ивенты в бизнесе» нет** — в базе нет связи место↔бизнес на 24.11.2026
(`places`, миграция 012, без `direction_id`; сказал `backend-uvedomleniya-b0`), ключа
`list` в ответе нет. Это ОТСУТСТВИЕ ПРЕДМЕТА, а не решение владельца: его слово о
составе страницы блока не отменяло. Экраном не обещать, ключей `partnerStats.list.*` не
заводить; появится связь в базе — блок возвращается рецептом.

## Запрещено

| запрещено | прибор |
|---|---|
| литеральное или демо-число (в т. ч. `70 %`/`30 %`) в разметке; `null` нулём | случай `ps-nol-ne-pusto`, признак `../34/masterStats.md` |
| доли за день или неделю, посчитанные в клиенте | случай `ps-doli-mesyac` |
| деньги второго бизнеса под первым | случай `ps-dva-biznesa` |
| блок «Ивенты в бизнесе» без связи место↔бизнес в базе | `rg -c 'partnerStats.list' js/` — 0 |
| русская строка в разметке, а не ключом | случай `ps-klyuchi` |

**Признак сборки** (ВХОЖДЕНИЯ):
`rg -c 'partnerStats.door' js/` — **сегодня 0, обязано стать 2**;
`rg -c 'partnerStats.noData' js/` — **сегодня 0, обязано стать 2**;
`python3 -I tools/v-oblasti.py <файл экрана> partnerStats '70'` — **обязано быть 0**;
`rg -c 'eventReport.money.cashNote' js/` — **остаётся 2**.

**Проверки** — по ветвям (три блока, выбор бизнеса) и одна сверх — на ключи:

- `ps-razrez` — день, неделя, месяц дают разные продажи, а `На кошельке` одно;
- `ps-doli-mesyac` — день и неделя → `H1`; закрытый месяц → доли с процентами сервера;
- `ps-dva-biznesa` — у партнёра двух бизнесов смена выбора меняет все числа;
- `ps-nol-ne-pusto` — `0` → `0`; `null` → `нет данных`; литерала числа и процента нет;
- `ps-dver` — у не-партнёра двери `B0` нет (отрицательный контроль);
- `ps-klyuchi` — каждый ключ экрана есть в словаре.
