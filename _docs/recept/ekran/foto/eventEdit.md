# `eventEdit` · блок «Фото» в правке события

Как `eventNew.md` (блок «Фото» — `masterApply.md`). Блок стоит после поля
«Коротко для афиши», перед ценой входа. Отличие одно: согласованное событие
(Ф2, №82 «а»).

| состояние события | вид блока |
|---|---|
| **не согласовано** | как `masterApply.md`: `P1`–`P9`, снимки можно добавить, убрать, переставить |
| **согласовано, снимки есть** | `P1`, `.album` (`P3` без `.album-cap` и без действий), под ним `F6` (`foto.frozen`, слово — `event.md`); `P2`, `P4`–`P9` нет |
| **согласовано, снимков нет** | `P1` и `F6`; `.album` нет, `P4` нет |

⚠ **Заморозку человек ВИДИТ до попытки** — строкой `F6` на месте кнопок, а не
отказом сервера после «Сохранить» (Ф2). Остальная правка (места, описание,
цена) у согласованного работает как сегодня.

**Признак сборки** (цель числом, путь обязателен, единица — ВХОЖДЕНИЯ):
`python3 -I tools/v-oblasti.py js/14-ekrany-meropriyatiya.js eventEdit 'foto.frozen'`
— **сегодня 0 (замер по `7bebcce`), обязано стать 1** — строка `F6` в форме.
