# `masterApply` · блок «Фото» в форме подачи события

Рецепт БЛОКА внутри чужого экрана: остальная форма — `../master/masterApply.md`.
`teaHold` и `eventNew` — как этот блок (`teaHold.md`, `eventNew.md`). Вид
кадров — `sostav.md`.

**Зритель:** тот, кто подаёт событие. Снимки выбираются ДО подачи; после
согласования их не меняют (№82 «а»), поэтому блок — единственное место правки.

## Слова

| что | ключ | слово |
|---|---|---|
| `P1` подпись | `foto.label` | `.label` `Фото` |
| `P2` под `P1`, ВСЕГДА | `foto.note` | `.small`: `До трёх снимков. Первый будет крупным.` |
| `P3` кадры | — | `.album`; у кадра `.album-cap`: `.btn quiet mini` `Убрать` (`foto.del`) и, кроме первого, `Сделать первым` (`foto.first`) |
| `P4` кнопка | `foto.add` | `.btn quiet` `Добавить фото` — при 0–2 кадрах; при трёх кнопки нет |
| `P5` кадр грузится | `foto.loading` | кадр на своём месте пустым квадратом `--surface`, в `.album-cap` `.small` `Загружаем…`; `Убрать` у него есть |
| `P6` снимок сжат | `foto.squeezed` | `.small` под `.album`: `Большие снимки уменьшили — так они быстрее открываются.` |
| `P7` файл больше 8 МБ | `foto.tooBig` | `.deny` под `.album`: `Снимок больше 8 МБ — выберите поменьше.` — проверка клиента до отправки |
| `P8` не снимок | `foto.notImage` | `.deny`: `Это не фото — выберите снимок.` — проверка клиента |
| `P9` не принят сервером | `foto.fail` | `.deny` → `.verbatim`: слово отказа как есть (`failText`/`denyText`); кадр убирается |

⚠ **`P6` — одна строка на блок, а не на кадр**, и стоит, пока форма открыта:
сама по таймеру не уходит (сжатие молча запрещено, №83 «а»). Уходит, когда
убраны все сжатые кадры. Условие «сжат» — Ф3 в `sostav.md`.

⚠ **`P7`, `P8`, `P9` — по одному за раз**, последний сверху; прежние кадры
остаются. Новый выбор файла снимает отказ.

⚠ **Кнопку подачи блок не гасит** (Ф1 «не обязателен»). Кадр в `P5` при
подаче: подача ждёт, пока он догрузится, — кнопка показывает `Загружаем фото…`
(`foto.wait`) и погашена.

## Блоки сверху вниз

`.card`: `P1`, `P2`, `P3`, `P6`, отказ `P7`–`P9`, `P4`. Стоит после полей
названия и описания, перед датой и ценой.

| состояние | вид |
|---|---|
| **кадров нет** | `P1`, `P2`, `P4` |
| **1–2 кадра** | `P1`, `P2`, `P3`, `P4` |
| **три кадра** | `P1`, `P2`, `P3`; `P4` нет |
| **грузится** | кадр `P5` в `P3`; `P4` есть, если кадров меньше трёх |
| **сжат** | `+ P6` |
| **отказ** | `+` один из `P7`–`P9` |

**Признак сборки** (цель числом, путь обязателен, единица — ВХОЖДЕНИЯ):
`rg -c 'foto\.squeezed' js/`
— **сегодня 0 (замер по `7bebcce`), обязано стать ≥ 2** — ключ и вызов;
`rg -c 'foto\.add' js/`
— **сегодня 0, обязано стать ≥ 2** — ключ и кнопка.
