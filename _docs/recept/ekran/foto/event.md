# `event` · снимки на карточке события

Рецепт БЛОКА внутри чужого экрана: остальное на `event` — как сегодня (и
`../odobrenie/event.md`). Вид кадров — `sostav.md`, таблица «Правка `.album`».

**Зритель:** любой, кто видит карточку события. Строку `F6` видит только автор
события (`isMyEvent`, `js/09-afisha.js`).

## Слова

| что | ключ | слово |
|---|---|---|
| `F1` снимки | — | `.album` без подписи, кадры в порядке, который задал автор; слов нет |
| `F6` под `F1`, у автора согласованного события | `foto.frozen` | `.small`: `Фото согласованы вместе с событием — заменить их нельзя.` |

## Блоки сверху вниз

`F1` стоит после метки одобрения и «Вы записаны», перед `.rows` («Ведёт»).

| состояние | вид |
|---|---|
| **три снимка** | крупный + два превью в ряд, все видны сразу |
| **два снимка** | два кадра рядом равными половинами |
| **один снимок** | один крупный |
| **снимок грузится** | кадр стоит на своём месте пустым квадратом `--surface` того же размера; слов и крутилки нет — карточка не прыгает, когда снимок пришёл |
| **снимок не загрузился** | тот же пустой квадрат (как у `.album` сегодня, `js/22-ekrany-chay.js:206–209`) |
| `F5` **снимков нет** | блока нет вовсе; карточка — как сегодня |
| **согласовано, смотрит автор** | `F1` и под ним `F6` |

⚠ **`F6` — только у согласованного.** У ждущего и у отклонённого строки нет:
там говорит `../odobrenie/event.md`, а снимки меняются только в форме подачи.
Строки о сжатии на `event` нет — она живёт в форме (`masterApply.md`, `P6`).

**Признак сборки** (цель числом, путь обязателен, единица — ВХОЖДЕНИЯ):
`rg -c 'foto\.frozen' js/`
— **сегодня 0 (замер по `7bebcce`), обязано стать ≥ 2** — ключ в словаре и вызов в `eventLive`;
`rg -c 'album-pair' js/`
— **сегодня 0, обязано стать ≥ 1** — вид «два кадра»: класс в `teaAlbum` (правило — в `styles.css`).

## Проверки

- `foto-tri` — три снимка → один крупный, два превью, все в окне без прокрутки карточки;
- `foto-dva` — два снимка → два кадра равными половинами, пустой половины ряда нет;
- `foto-odin` — один снимок → только крупный;
- `foto-net` — снимков нет → `.album` в разметке нет, остальная карточка не сдвинута;
- `foto-gruzitsya` — снимок отдаётся с задержкой → квадрат на месте, высота блока до и после одна;
- `foto-ne-zagruzilsya` — адрес кадра отвечает ошибкой → пустой квадрат, соседние кадры видны;
- `foto-zamorozheny` — автор, событие согласовано → `F6`; гость того же события → `F6` нет.
