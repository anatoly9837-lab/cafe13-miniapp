# `eventReport` · отчёт по одному ивенту: записи, деньги, распределение

**Один рецепт на все страницы статистики** (слово владельца 24.11.2026,
дословно, передано координатором: «…с возможностью провалиться в каждый и
посмотреть статистику по ивенту. Этот же отчет по ивенту будет показан
мастеру»). Первый вход — список `L` на `masterStats` (шаг 34); страница 36 и
`artStats` ведут СЮДА же, а не в свою копию. У страниц 33 и 35 списка `L` НЕТ:
в базе нет связи место↔бизнес (24.11.2026, `places` без `direction_id`) — входа
оттуда нет, экраном его не обещать.

**Зритель:** любой, кому ивент пришёл в списке `L` его страницы статистики
(шаги 34, 36, `artStats`) — от гостя до админа.
Право решает сервер (403 словами сервера), клиент двери не вычисляет.

**Состав урезает СЕРВЕР по роли зовущего** (решение координатора 24.11.2026; клиент прав не судит):

| зовущий | в ответе ручки |
|---|---|
| автор ивента, `art_director`, `head`, админ | всё: ивент, время, место, записи, `money`, `slot_fee` |
| гость и прочий зритель (в т. ч. со страницы «моя», шаг 36) | ивент, время, место, записи; ключей `money` и `slot_fee` В ОТВЕТЕ НЕТ |

Ключа нет — блока нет: карточки `M` и `S` не рисуются вовсе, ни пустыми, ни со
словом «нет данных». Это ТРЕТЬЕ состояние числа, отличное от `0` и от `null`:

| в ответе | на экране |
|---|---|
| `0` | `.num` с `0` |
| `null` | `.small` `нет данных` (`eventReport.noData`) |
| ключа нет | карточки нет |

⚠ Пустое место (карточка без числа, прочерк) там, где у мастера число, —
расхождение для описи, «программист накосячил»: разметка прячет то, что сервер
прислал, или рисует то, чего он не прислал.

⚠ **Состав отчёта — ПРЕДПОЛОЖЕНИЕ дизайнера**: владелец назвал «статистику по
ивенту», числа не назвал. Ниже выведено из того, что о ивенте уже знает
сервер (запись, оплата, распределение 85/15 шага 7, плата за слот). Ручка `/stats/event/{event_id}` есть в
стволе api (`app/routers/stats.py:707`, main d6ea79b), в бою её нет до выкладки.

⚠ **Код клиента не читался** (правило `Cafe13KPG#975`). Тексты — ключами
`eventReport.<блок>.<слот>` (№22), словарь `js/00-slova.js`.

## Числа — только из ручки

Правило и признак — `masterStats.md`, раздел «Числа — только из ручки» (слово владельца 24.11.2026 «Числа нужны. Реальные. Если нули - значит нули.», класс `Cafe13KPG#964`). Ключ здесь — `eventReport.noData`, слово `нет данных`.

## Блоки сверху вниз

| класс | слова | источник |
|---|---|---|
| заголовок | `title` | сервер |
| `.small` | `R0` | `starts_at` |
| `.card` + `.rows` | `B` (`B1` вместо мест) | `bookings{count,places}` |
| `.card` + `.rows` | `M` (`M1` вместо долей), `N1` `.small` | `money{collected,master,club,distributed}` |
| `.card` + `.rows` | `S` | `slot_fee` |
| `.deny` → `.verbatim` | отказ 403 | ответ сервера, как есть |

Числа — `.num`, деньги — числом сервера с `฿`. Доли НЕ считаются в клиенте:
`master` и `club` — числа сервера по факту распределения.

## Данные экрана

- `GET /stats/event/{event_id}` — есть в стволе api (`stats.py:707`, d6ea79b), в
  бою нет до выкладки; форма ниже со снимком сервера НЕ сверена; одна на всех зрителей, право — сервера;
- `money.distributed = false` → `M1`; доли не выдумываются;
- список записавшихся по именам — НЕ здесь: он у автора на «Свои ивенты»
  (`organizer`), отчёт — числа.

## Запрещено

| запрещено | прибор |
|---|---|
| литеральное или демо-число в разметке; `null` напечатан нулём | случай `er-nol-ne-pusto`, признак раздела «Числа — только из ручки» |
| вторая копия отчёта на другой странице статистики | признак `rg -c 'eventReport.money.cashNote' js/` = 2 (словарь + один экран) |
| считать доли в клиенте | случай `er-doli-servera` |
| `0 ฿` вместо `M1` у нераспределённого | случай `er-ne-raspredelen` |
| имена записавшихся в отчёте | случай `er-bez-imen` |
| русская строка в разметке, а не ключом | случай `er-klyuchi` |

**Признак сборки** (ВХОЖДЕНИЯ):
`rg -c 'eventReport.money.cashNote' js/` — **сегодня 0, обязано стать 2**
(словарь и экран; 3 и больше — копия отчёта).

**Проверки** — по ветвям (три блока, вход) и одна сверх — на ключи:

- `er-vhod` — строка `L` на `masterStats` открывает отчёт своего ивента; назад — тот же период;
- `er-ne-raspredelen` — нераспределённый → `M1`, а не `0 ฿`;
- `er-doli-servera` — «Мастеру» и «Клубу» равны числам сервера как есть;
- `er-bez-imen` — имён записавшихся нет;
- `er-gost` — гость открывает отчёт по чужому ивенту: ивент, время, место, записи есть; в ответе нет `money` и `slot_fee` — карточек `M` и `S` нет, ни пустых, ни «нет данных» (признак «нет поля» ≠ «ноль»: `0` даёт `.num` с `0`, отсутствие — ни одной `.card` денег);
- `er-chuzhoy` — ивент, которого нет в списке смотрящего (прямой адрес) → 403 словами сервера (отрицательный контроль);
- `er-nol-ne-pusto` — поле `0` → `.num` с `0`; поле `null` → `нет данных`, а не `0`; литерала числа в разметке нет;
- `er-klyuchi` — каждый ключ экрана есть в словаре.
