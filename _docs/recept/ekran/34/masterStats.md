# `masterStats` · статистика мастера: свои ивенты, записи, выплаты и свой счёт за день, неделю, месяц

**Зритель:** тот, кто ведёт свои ивенты, — условие двери `mayOwnEvents()`
(мастер, организатор, работник; членство не требуется — рамка 24.11.2026).
Право — видеть СВОЮ работу: свои ивенты, записи на них, выплаченное ему и
свой счёт. ⚠ Название «Статистика мастера», а не «Моя»: по №42 «а» (24.11.2026) «моя» — страница шага 36. Чужие ивенты, касса, бизнесы, счета ролей — не сюда.

⚠ **ТЗ шага нет** (`Cafe13KPG#565` называет одну цель), **ручки нет**
(`cafe13-api` ствол: только `/stats/club` и `/stats/art`), **слов владельца о
числах нет** — список чисел ниже ПРЕДЛОЖЕН (ПРЕДПОЛОЖЕНИЕ, №51) по образцу `../32/artStats.md` и
отправлен владельцу через координатора 24.11.2026. Каждое число — ПРЕДПОЛОЖЕНИЕ
до его «да»; вычеркнутое снимается строкой таблицы, не правкой клиента.

⚠ **Код клиента не читался** (правило `Cafe13KPG#975`), кроме места двери
(`js/17-ekrany-upravlenie.js`, группа «Ивенты»).

**Все тексты — ключами перевода** (№22): вид `masterStats.<блок>.<слот>`,
словарь `js/00-slova.js`, экран — `js/18-ekrany-mastera.js`. Слова сервера
(`detail` отказа) — не ключи.

## Данные экрана

- `GET /stats/master?period=day|week|month&at=YYYY-MM-DD` — НОВАЯ ручка, смотрящий
  = сам (`caller`), чужого `member_id` в запросе нет; наряд серверу — через
  координатора (ПРЕДПОЛОЖЕНИЕ формы до снимка со sha api);
- `events` — ивенты, где смотрящий автор, только одобренные (№48 «б»: в афише —
  одобренный); отменённые и отклонённые не считаются (ВЫБОР);
- `payouts` — строки распределения на личный счёт смотрящего за окно (доля
  мастера, шаг 7);
- `money.balance` — тот же остаток, что `/me`; `money.withdrawable` — то же
  поле (смысл «можно вывести» зависит от развилки №18 «а» / `#991` «целиком», вопрос у координатора 24.11), что `GET /withdraw/accounts` → `personal.withdrawable` (фича 6, ствол api
  `279a554`); `money.expected` — доля мастера по его прошедшим нераспределённым
  ивентам;
- прозы в ответе нет: надписи — ключи клиента;
- плата за слот 100 ฿ — другой канал денег, сюда НЕ входит (вне списка, на
  который спрошено «да»).
