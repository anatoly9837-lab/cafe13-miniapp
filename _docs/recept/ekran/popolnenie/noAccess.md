# `noAccess` · выгнанный просит вернуться — без денег и без суммы

**Рецепт ЧАСТИЧНЫЙ:** только смысл формы просьбы после фичи 8. «О клубе»
(`joinAbout`) и ожидание ответа — как сегодня.

**Зритель:** после фичи 1 (дверь, `../dver/home.md`) на `noAccess` попадает
ТОЛЬКО выгнанный (`revoked_at`): новичок входит сразу. Согласие главы клуба
на просьбу СНИМАЕТ отзыв допуска (`join.py:430–433`).

**Решение координатора** (`Cafe13KPG#1009`, три решения по фиче 8, пункт 1):
`noAccess` — «выгнанный просит вернуться», **без денег и без суммы**.
Пополнение с чеком — путь ИЗ КОШЕЛЬКА, доступный любому (`topup.md`).
⚠ Код клиента не читался (`#975`).

## ⚠ Предусловие: серверная правка — ДО клиента

Сегодня (`f89d540`) `POST /join/request` требует чек (`receipt_base64`) и
`amount_thb` > 0 (api #180), а согласие кладёт сумму на счёт. Форма без
денег уйдёт с 422. **Клиент этой формы — только после правки сервера**:
просьба вернуться без чека и суммы, согласие без строки книги. Чей наряд и
номер — у координатора; до неё форма `noAccess` не трогается этой фичей.
