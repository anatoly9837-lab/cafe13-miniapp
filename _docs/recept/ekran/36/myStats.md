## Данные экрана

- `GET /stats/me?period=day|week|month&at=YYYY-MM-DD` — смотрящий = сам;
- `events` — свои записи на ивенты окна, отменённые не считаются (ВЫБОР);
- `topups` — зачисленные пополнения окна (онлайн и касса), отклонённые не считаются (ВЫБОР);
- `money.balance` — тот же остаток, что `/me`;
- бар сюда не входит: покупок бара в списке владельцу не было (вне «да»).

`rg -c 'myStats.door' js/` — **сегодня 0, обязано стать 2** (словарь и дверь);
`rg -c 'myStats.noData' js/` — **сегодня 0, обязано стать 2**;

- `my-nol-ne-pusto` — поле `0` → `0`; `null` → `нет данных`; литерала числа нет;
