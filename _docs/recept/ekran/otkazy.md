# Отказы: что человек видит, чьими словами, и чем «нельзя» отличается от «не хватает»

Рецепт ОТКАЗОВ пяти экранов, у которых опись (`#387`) не могла снять вид отказа:
`roleAccount`, `withdraw`, `withdrawQueue`, `clubStats`, `artStats`. Свой рецепт
экрана называет класс (`.deny` → `.verbatim`); здесь — КОГДА отказ бывает, КАКИМИ
словами и ЧТО остаётся на экране. Опись снимает вид по строкам таблиц ниже: код и
слова сервера — то, что кладётся в фикстуру.

**Сервер:** слова сняты с `cafe13-api` `410f240` (`app/routers/withdraw.py`,
`app/deps.py:277` `require_role`, `app/deps.py:248` и `:253` — имена ролей).
Бой `/health` = `29a088c` (24.11.2026); оба файла на бою и в стволе api
совпадают по всем строкам отказов (`git diff 29a088c 410f240` строк отказа не
содержит). Сменятся слова на сервере — меняется эта таблица, не клиент.

## Три вида — и ни один не подменяет другой

| вид | когда | класс | чьи слова | кнопка |
|---|---|---|---|---|
| **нельзя** (нет права) | клиент сам знает, что роли нет | `.card quiet`: заголовок + `.small` | клиента (у `artStats` — ключи `artStats.denyTitle`, `artStats.denyNote`) | нет |
| **отказ сервера** | сервер ответил 403 / 404 / 409 со словом (`detail`) | `.deny` (`role="alert"`) → `.verbatim` | сервера, ДОСЛОВНО | нет «Повторить»: повтор того же запроса даст тот же отказ |
| **не загрузилось** | сервер не ответил (0), 5xx, ответ без слова | `.card quiet` + `Повторить` | клиента (`failText`) | `Повторить` |

- **Дословно** значит: `detail` сервера как есть, со строчной буквы и без точки
  (`detailOf` у статистики, `wdServerWord` у вывода). Ни слова сверху — ни
  «Ошибка», ни «Не удалось». Свой текст клиент пишет только тогда, когда слова у
  сервера НЕТ (`failText`: «Сервер ответил кодом N.»).
- **«Нельзя» и «не хватает» различаются словом сервера, а не цветом.** Оба —
  `.deny` глиной. «Нельзя» называет, КТО это делает («это делает глава клуба»,
  «счёт клуба выводит глава клуба»): человеку нечего исправить, поле суммы ему не
  поможет. «Не хватает» называет ДВА ЧИСЛА («на счёте 300 ฿ — вывести 500 ฿
  нельзя»): человек может исправить сумму, и поле суммы ОСТАЁТСЯ с введённым.
- **403 при ЗАГРУЗКЕ — тоже отказ, а не «не загрузилось».** Экран показывает
  `.deny` со словами сервера на месте списка, без `Повторить`. Так уже собраны
  `clubStats` и `artStats` (`CS.deny`, `AS.deny`). ⚠ **Рецепт впереди кода:**
  `withdraw`, `withdrawQueue`, `roleAccount` сегодня кладут 403 загрузки в
  «Запросы не загрузились» / «Счёт не загрузился» с `Повторить`
  (`js/18-ekrany-mastera.js:97`, `js/17-ekrany-upravlenie.js:294` и `:324`).
  Это работа руки клиента по этому рецепту, не расхождение описи.

## `withdraw` — вывод со своего счёта (`POST /withdraw/request`, `account = personal`)

| код | когда | слова сервера | что остаётся |
|---|---|---|---|
| 409 | сумма больше остатка | `на счёте {balance} ฿ — вывести {amount} ฿ нельзя` | форма, введённая сумма |
| 409 | сумма в остатке, но больше заработанного | `заработано к выводу {can} ฿ — вывести {amount} ฿ нельзя` | форма, введённая сумма |
| 409 | свой ждущий запрос уже есть | `ваш запрос на вывод с этого счёта уже ждёт решения` | форма; строка ждущего в списке |
| 403 | смотрят «чужими глазами» | `вывод денег чужими глазами не делается` | форма |
| 409 | отмена не своего / не ждущего (`…/cancel`) | `отменить можно только свой ждущий запрос` | строка запроса |

Первые две — «не хватает»: сервер проверяет остаток ПЕРВЫМ, заработанное —
вторым, поэтому при нехватке обоих человек видит слово про остаток.

## `roleAccount` — вывод со счёта роли (`account` = роль)

| код | когда | слова сервера | что остаётся |
|---|---|---|---|
| 409 | сумма больше остатка счёта роли | `на счёте {balance} ฿ — вывести {amount} ฿ нельзя` | форма, сумма |
| 409 | ждущий запрос с этого счёта уже есть | `ваш запрос на вывод с этого счёта уже ждёт решения` | форма |
| 403 | счёт чужой роли | `счёт арт-директора выводит держатель этой роли` · `счёт управляющей пространством выводит держатель этой роли` · `счёт клуба выводит глава клуба` · `счёт операционного директора выводит держатель этой роли` | форма |
| 403 | «чужими глазами» | `вывод денег чужими глазами не делается` | форма |

Заработанное у счёта роли не проверяется — только у `personal`.

## `withdrawQueue` — решение администратора (`POST /withdraw/requests/{id}/decide`)

| код | когда | слова сервера | что остаётся |
|---|---|---|---|
| 403 | не администратор (и при загрузке очереди) | `вывод денег одобряет администратор клуба` | при решении — карточка; при загрузке — `.deny` вместо очереди |
| 404 | запроса нет | `такого запроса нет` | карточка |
| 409 | запрос уже решён или отменён | `запрос уже {одобрено / отказано / отменено}` | карточка |
| 409 | остаток упал с подачи | `на счёте сейчас {balance} ฿, а запрос — {amount} ฿: остаток изменился после подачи` | карточка |
| 409 | заработанное упало с подачи | `заработано к выводу сейчас {can} ฿, а запрос — {amount} ฿` | карточка |

`.deny` — внутри карточки ЭТОГО запроса, не над очередью: администратор видит,
какой запрос сервер не принял. Карточка остаётся — запрос решает сервер, экран
его не убирает; уйдёт она с перечитыванием очереди.

## `clubStats` и `artStats` — только «нельзя»

| экран | вид | слова | откуда |
|---|---|---|---|
| `clubStats` | роли нет у клиента | `Сюда нельзя` · `Статистику клуба видит глава клуба.` | клиент |
| `clubStats` | 403 сервера | `это делает глава клуба` | сервер (`require_role("head")`) |
| `artStats` | роли нет у клиента | ключи `artStats.denyTitle`, `artStats.denyNote` | клиент |
| `artStats` | 403 сервера | `это делает тот, кто отвечает за мероприятия` | сервер (`require_role("art_director")`) |

`admin` проходит любой `require_role` — 403 у него не бывает. 403 сервера при
видимой двери бывает, когда роль сняли после того, как экран открыт: переключатель
периода и стрелки остаются, `.deny` стоит на месте чисел.

## Для описи: что снимать

Один вид на строку «отказ сервера» каждого экрана достаточен: класс один. Для
`withdraw` — два вида, потому что «нельзя» и «не хватает» различаются тем, что
ОСТАЁТСЯ (сумма в поле): 409 по остатку и 403 «чужими глазами». Фикстура несёт
`{"detail": "<слово из таблицы>"}` и код; слово берётся из таблицы, а не
придумывается.
