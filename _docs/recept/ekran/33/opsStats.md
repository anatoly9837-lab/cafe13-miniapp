# `opsStats` · статистика операционного директора: бизнесы клуба, доли, закрытые месяцы и его 3 %

**Зритель:** держатель роли `ops_director`, админ проходит — право ровно
`_is_ops` сервера (`cafe13-api` `app/routers/profile.py:240`; клиент —
`mayOps()`, `js/06-lyudi.js:779`). Право — видеть ВСЕ бизнесы клуба, их доли
и закрытые месяцы (шаги 12, 21).

**Слова владельца, на которых страница стоит** (STAGE.md dev `0f0f365`, через
летописца):
- №16 «а» 24.11.2026 — «Страница без своих денег: бизнесы, доли, закрытые
  месяцы» ПЛЮС его уточнение дословно: «А + 3% это его деньги»;
- №17 24.11.2026, дословно: «3% от бизнесов, так же как у арт директора».

Поэтому блок `D` «Мои 3 %» в рецепте ЕСТЬ, но счёта роли `ops_director` в книге
сервера ещё НЕТ (`club_ledger.account` — club / art_director / space_manager /
business, миграция 033; шаг 28 несёт миграцию, срок владельца 01.12.2026).
До неё ключа `money` в ответе нет → карточки `D` нет (три состояния числа —
`../34/eventReport.md`); с миграцией карточка встаёт сама, без правки рецепта.

**Образец — шаг 34** (`../34/masterStats.md`, PR #400): «да» владельца на форму и
список ивентов с проходом в отчёт. **СОСТАВ чисел ниже — ПРЕДПОЛОЖЕНИЕ
дизайнера** в каждой строке, где он назван; блоки бизнесов, долей и месяцев —
слово владельца №16. Списка ивентов на этой странице НЕТ — см. «Блока `L` нет».

⚠ **Ручки нет** — `GET /stats/ops` НОВАЯ, наряд серверу через координатора.
⚠ **Код клиента не читался** (правило `Cafe13KPG#975`), кроме права `mayOps()`.
Тексты — ключами `opsStats.<блок>.<слот>` (№22).

## Данные экрана

- `GET /stats/ops?period=day|week|month&at=` — НОВАЯ ручка, право `_is_ops`;
- `businesses` — все активные бизнесы клуба (`is_active: false` — не идут, как шаг 12);
- `months` — закрытые месяцы, попавшие в окно (вариант C шага 20);
- `money` — счёт роли `ops_director`: ключа НЕТ, пока нет строки книги (шаг 28).

**Блока `L` «Ивенты в бизнесах» нет** — в базе нет связи место↔бизнес на 24.11.2026
(`places`, миграция 012, без `direction_id`; сказал `backend-uvedomleniya-b0`), ключа
`list` в ответе нет. Это ОТСУТСТВИЕ ПРЕДМЕТА, а не решение владельца: его слово о
составе страницы блока не отменяло. Экраном не обещать, ключей `opsStats.list.*` не
заводить; появится связь в базе — блок возвращается рецептом.

## Запрещено

| запрещено | прибор |
|---|---|
| литеральное или демо-число (`3 %`, `70 %`, `30 %`) в разметке; `null` нулём | случай `os-nol-ne-pusto`, признак `../34/masterStats.md` |
| карточка `D` с `0` или «нет данных», когда ключа `money` нет | случай `os-bez-scheta` |
| подпись месяца из `month` сервера | случай `os-mesyac-poyas` (`Cafe13KPG#961`) |
| блок «Ивенты в бизнесах» без связи место↔бизнес в базе | `rg -c 'opsStats.list' js/` — 0 |
| русская строка в разметке, а не ключом | случай `os-klyuchi` |

**Признак сборки** (ВХОЖДЕНИЯ):
`rg -c 'opsStats.door' js/` — **сегодня 0, обязано стать 2**;
`rg -c 'opsStats.noData' js/` — **сегодня 0, обязано стать 2**;
`rg -c 'Мои 3' js/` — **обязано быть 0** (процент — подстановкой `{pct}`);
`rg -c 'eventReport.money.cashNote' js/` — **остаётся 2**.

**Проверки** — по ветвям (четыре блока, список, дверь) и одна сверх — на ключи:

- `os-bez-scheta` — ответ без `money` → карточки `D` нет; с `money` → `D` с числами сервера;
- `os-razrez` — день, неделя, месяц дают разные продажи; доли бизнесов — одни;
- `os-mesyac-poyas` — граница `2026-10-31T17:00Z` подписана «Ноябрь», не «Октябрь»;
- `os-nol-ne-pusto` — `0` → `0`; `null` → `нет данных`; литерала числа и процента нет;
- `os-dver` — без `ops_director` и `admin` двери `O0` нет (отрицательный контроль);
- `os-klyuchi` — каждый ключ экрана есть в словаре.
