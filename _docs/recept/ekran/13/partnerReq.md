`partnerReq` — решение

**Зритель:** `_is_ops`. **Вход:** `.listitem` очереди. **Выход:** решение →
`partnerReqs` со вспышкой.

| класс | слова | источник |
|---|---|---|
| `.bar` | название бизнеса | `title` |
| `.card` → `.small` | имя заявителя · когда подана | очередь |
| `.card quiet` → текст тушью | описание целиком, переводы строк заявителя сохранены | `about` |
| `.rows` | «Списано» · сумма | `amount` |
| `.btn` | «Согласовать» | моё |
| `.btn quiet` | «Отказать» | моё |
| `.field` (после «Отказать») | `.label` «Причина отказа» · подсказка «Что исправить, чтобы согласовали» | моё; требование — `decide`, 400 |
| `.note` | «Согласие создаёт бизнес и начинает оплаченный месяц. Отказ вернёт деньги заявителю.» | моё; механика — `decide` |
| `.deny` → `.verbatim` | печать отказа сервера | `decide` |
| вспышка «да» | «Согласовано» · «Бизнес „…“ создан.» | `title` из очереди |
| вспышка «нет» | «Отказано» · «Деньги вернулись на счёт заявителя.» | моё |

**Данные экрана:** `POST /partner/requests/{id}/decide` ← `decision`, `note`;
ответ → `status`, `decided_at`, `direction_id`.

**Состояния:** пусто — нет; `.sending` на отправке; отказы сервера по адресам
(`decide`): 404 — такой заявки нет; 409 — своя заявка; 409 — уже решена, со
словом статуса; 400 — отказ без причины. «Не загрузилось» относится к очереди.

⚠ **Ответ `decide` не отдаёт ни названия, ни `paid_till`** (замер: возвращает
`id`, `status`, `decided_at`, `refund_ledger_id`, `direction_id`). Поэтому
«Оплачено до …» здесь НЕ печатается: название берётся из уже загруженной
очереди, а дата окна появится на экране партнёра (`home` → блок «Свой бизнес в клубе») после перечитывания.
Печатать дату здесь было бы правдоподобным вместо известного.

**Перечитать на входе:** очередь — после отказа 409 («уже решена»): экран
должен показать, кем и как решено, а не повторить отказ.

**Усечение:** описание — без обрезки, `.card quiet` растёт: решение опирается
именно на него, и подписью (`.small`, 12 px приглушённым) оно быть не может.
Название в `.bar` — `.clamp2`.

**Запрещено:** доля, `%`, любое число доли клуба (случай 13.4 — доли пусты до
шага 21 по миграции 031); «Отказать» без причины (запрет построением: отправка
не работает при пустом поле, и слова сервера на случай обхода); телеграм-id в
разметке (`ids-clean.cjs`).

**Признак сборки** (цель числом):
`rg -o 'partnerReq: function' js/17-ekrany-upravlenie.js | wc -l` — **вхождений сегодня 0,
обязано стать 1**. Образец с двоеточием, а не `partnerReq\b`: граница слова
ловит и `partnerReqs`, то есть соседний экран.

Плюс случаи 13.4 «отказ без причины не отправляется» и «свою заявку решить
нельзя».
