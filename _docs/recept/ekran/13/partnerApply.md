`partnerApply` — форма заявки

**Зритель:** тот же. **Вход:** `.btn` «Я партнёр» на `home`. **Выход:** успех
→ `home` со вспышкой; `.icon-btn` назад → `home`.

| класс | слова | источник |
|---|---|---|
| `.bar` | «Заявка в партнёры» | моё |
| `.field` | `.label` «Название бизнеса» · подсказка «Как его назовут гости» | моё |
| `.field` | `.label` «О бизнесе» · подсказка «Одной строкой: чем он занимается» | моё |
| `.rows` | «Спишется сейчас» · сумма | `GET /partner/price` |
| `.rows` | «На счёте» · остаток | `/me` |
| `.btn` | «Подать заявку» | моё |
| `.note` | «Решение принимает операционный директор. Если он откажет, деньги вернутся на счёт.» | моё |
| `.deny` → `.verbatim` | печать отказа сервера целиком | `_create_request` |
| вспышка успеха | «Заявка отправлена» · «Списано N ฿. Решение примет операционный директор; если он откажет, деньги вернутся на счёт.» | число — `amount` ответа 201 |

**Данные экрана:** `POST /partner/request` ← `title`, `about`; ответ 201 →
`amount`, `status_ru`. Цена и остаток — до нажатия.

**Состояния:** пусто — нет, форма есть всегда; отказ — `.deny` с `.verbatim`,
поле НЕ очищается; `.sending` на время отправки; «не загрузилось» относится к
цене (см. `home` → блок «Свой бизнес в клубе»).

**Отказы сервера — словами сервера, по адресам:** `_create_request` даёт 400
(пустое название), 403 (нет живого членства), 409 (не хватает на счёте — с
числами сервера), 409 (вторая ждущая заявка, `partner_requests_one_pending`).
К каждому сервер дописывает `REQUEST_NOT_CHARGED`; завершающую точку ставит
клиент (`denyText`).

⚠ Клиентской арифметики на экране нет: «спишется» и «не хватает» — числа
сервера. Своя арифметика поставила бы правдоподобное вместо известного.

**Перечитать на входе:** остаток и цену.

**Усечение:** ввод — пределы сервера (название 1–200, описание до 2000),
обрезки в поле нет; длиннее предела — отказ сервера его словами.

**Запрещено:** доля и `%` (случай 13.4); слово «направление» о бизнесе (случай
13.4 — слово владельца «бизнес»); обещание, что бизнес появится сразу (его
создаёт СОГЛАСИЕ); слово «календарный».

**Признак сборки** (цель числом):
`rg -o 'partnerApply: function' js/17-ekrany-upravlenie.js | wc -l` — **до сборки 0 (замер по `97da7f0`), обязано стать 1**. Образец — ОБЪЯВЛЕНИЕ функции экрана, а не имя ключа: имя
встречается и в дверях (`js/21-navigaciya.js`), то есть шире предмета.

⚠ «Подать заявку» признаком не годится вовсе: в стволе это слово уже стоит у
заявки МАСТЕРА (`js/10-utility.js:116`), то есть подтвердило бы сборку чужим
экраном.
