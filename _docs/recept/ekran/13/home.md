`home` — блок «Свой бизнес в клубе»

**Зритель:** член клуба с живым членством (право — `LIVE_MEMBERSHIPS_SQL`;
гость блока не видит вовсе). **Вход:** вкладка «Клуб», под карточкой членства,
ниже блока мастера. **Выход:** `.btn` → `partnerApply`; при нехватке денег
двери нет, есть `.note` о кошельке.

| класс | слова | источник |
|---|---|---|
| `.card` → `b` | «Свой бизнес в клубе» | моё |
| `.small` | «Название, описание и оплаченный месяц. Что в бизнесе появится дальше — следующий шаг.» | моё |
| `.small` | «N ฿ в месяц» | `GET /partner/price` — **ручки нет, см. «Заказ серверу»** |
| `.small` | «Месяц идёт от даты оплаты. Продлевается оплатой, без новой заявки.» | моё; модель — шапка `partner.py`, слово владельца 06.11.2026 |
| `.btn` | «Я партнёр» | карточка `#887` |
| `.note` (денег мало) | «Пополнить счёт можно на вкладке „Клуб“ — кошельком в шапке.» | та же форма, что у `masterOffer` |

**Данные экрана:** `GET /partner/requests/mine` → `title`, `amount`, `status`,
`status_ru`, `decision_note`, `created_at`, `decided_at`, `paid_till`;
остаток — `/me`; цена — ручки нет.

**Состояния блока**, в этом порядке проверки:

| состояние | вид |
|---|---|
| цены ещё нет | `.small` «Узнаём цену…», `.btn` ПОГАШЕНА |
| цену не узнать | `.small` «Цену не удалось узнать у сервера.», `.btn` погашена |
| не хватает денег | `.small` «Не хватает N ฿: нужно M ฿, на счёте B ฿», `.btn` погашена, `.note` о кошельке |
| заявка ждёт | `.card quiet` → `b` «Заявка в партнёры» + `.small` дата + `.st wait` слово статуса сервера + `.small` «Списано N ฿.»; `.note` «Решение принимает операционный директор. Если он откажет, деньги вернутся на счёт.» Кнопки нет |
| отказали | та же карточка, `.st no` + `.said` причина словами решавшего + `.small` «N ฿ вернулись на счёт.» + `.btn` «Подать заново» → `partnerApply` |
| согласовано | `.card` → `b` «Вы партнёр бизнеса „…“» + `.small` «Оплачено до ДД.ММ.ГГГГ» |
| не загрузилось | `.card quiet` «Заявки в партнёры не загрузились: <причина>» + `.btn quiet` «Повторить» — кнопка ЖИВА, это не отказ |

⚠ **`paid_till` — МОМЕНТ, а не день.** Печатать формой «до ДД.ММ.ГГГГ» по дате
этого момента по часам клуба. Второго поля («последний покрытый день», как
`paid_until` у мастера) у партнёра НЕТ — не выдумывать и не вычитать день:
«до» читается исключающе и не лжёт ни в один час окна.

⚠ Причина отказа — `.said`, а не `.verbatim`: это слова живого человека,
решавшего заявку, а не печать сервера.

**Перечитать на входе:** свою заявку и остаток — остаток здесь решает, гасить
ли кнопку (правило `Cafe13KPG#638`).

**Усечение:** название бизнеса в «согласовано» — `.clamp2`, две строки;
предел ввода 200 знаков (`NewPartnerRequest.title`).
