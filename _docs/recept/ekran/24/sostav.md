`staff` и `tillPerson` (рецепт `tillMembership.md`). Разрешённые шкалы и
уровни — `../../sostav-shkaly.md`. **Числа здесь не повторяются:** состав
называет УРОВЕНЬ, значение живёт в шкале.

БРЕНДБУКУ и по рецептам форм шага 21 (поля, отказ дословно), а не по разметке
`tillForm`. Совпадение с разметкой — ПРЕДПОЛОЖЕНИЕ, его судит опись.

## Что этому предмету ЗАПРЕЩЕНО

| запрещено | прибор |
|---|---|
| цена вида в поле суммы | случай `kassa-summa-ne-cena`: при подставленной цене сверка не различает ничего |
| доля или остаток клуба, посчитанные клиентом как итог | итог `T8`/`T9` — из ответа сервера |
| допуск без оплаты | случаи `kassa-novichok-bez-oplaty`, `prishel-ne-daet-nichego` |
| просьбы о вступлении на экране кассира | слово `T12`; просьбы решает `head` |
| поле Telegram id у кассира | признак `'userinfobot'` → пусто; id приходит нажатием «Я у кассы» |
| открыть пополнение, мероприятие, услугу, день кассы | `tillTopup` и `tillDay` остаются в `FROZEN` |
| телеграм-id и живое имя в разметке | `tools/ids-clean.cjs`, шаг 7 ворот |

## Что сборка обязана тронуть, кроме экрана

| место | что встаёт |
|---|---|
| `FROZEN` (`js/02-chlenstvo.js:370–371`) | снимаются `staff`, `tillPerson`, `tillMembership`; `tillTopup`, `tillDay` остаются |
| `../bar/sostav.md`, строка «оттаивать вместе с витриной…» | из перечня ключей, которые обязаны остаться в `FROZEN`, уходят `staff`, `tillPerson`, `tillMembership` — правится ТЕМ ЖЕ PR, что разморозка (как на шагах 15 и 22); число берётся с дерева сборки |
| список пришедших к кассе | НОВАЯ таблица сервера (миграция шага 24); ручки списка и приёма взноса по пришедшему — имени в рецепте нет НАРОЧНО, назовёт сервер снимком формы в карточку `#555` со sha api |
| `tillSend` и ответ `POST /till` | итог `T8`/`T9` читается из ответа: доля на счёт и срок — числами сервера |
| комментарий «Цен членства на сервере нет» (`js/05-kassa.js:9`) | снять: устарел с 018 |

## Чего этот состав НЕ несёт

- возврата взноса и отмены членства — шаг 38;
- пересчёта валюты — доля в батах (слово владельца 28.10);
- сверки `memberships.ledger_id` между путями — долг в журнал, не шаг;
- `tillTopup` и `tillDay`;
- возврата снятого допуска: касса его не возвращает (409), это шаги 38/39.
